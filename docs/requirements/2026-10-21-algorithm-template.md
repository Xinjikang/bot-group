# 算法研发项目模板

## 范围
提供通用算法研发模板，兼顾传统算法与机器学习。四角色为研发负责人、算法研究员、算法工程师和评审员；负责人管理需求与任务，研究员负责文献、方案和报告，工程师实现与实验，评审员独立审查及复现。

## 协作与交付
目标及验收标准 → 文献与基线 → 算法方案和实验计划 → 实现、自测与实验 → 独立评审及修订复审 → 最终报告与用户验收。明确资源预算与停止条件；分别记录任务完成情况和指标达成情况，保留负面实验及其依据。

## 文件边界
- docs/requirements 保存目标、约束、指标和验收标准。
- docs/literature 保存文献索引、阅读笔记与方法对比。
- docs/design 保存算法方案、推导和实验计划。
- docs/engineering 登记实际工程结构、环境与运行说明。
- 项目主目录 reports/experiments 保存逐次实验记录与原始证据，reports 保存面向用户的最终报告。

源码、Demo、配置、数据及模型目录由用户管理。实验计划与算法方案合并维护，最终综合结论写入报告。模板生成待填写骨架，报告与证据采用主目录忽略和备份约定。

## 验收
新建和导入向导可选算法研发；角色参考、改名、授权、共享目录与 worktree、预览落盘、既有文件保护及历史模板恢复有效。验证实验复现信息、报告归属与 Git 排除、源码包模板资源保留，以及浏览器创建、刷新和窄屏操作。说明见[算法研发模板](../engineering/ALGORITHM-TEMPLATE.md)。
