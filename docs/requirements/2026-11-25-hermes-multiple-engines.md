# 同一 Hermes profile 同时接入多个 Bot-group

状态：需求已确认，待实现。

同一个 Hermes 网关中的同一个 profile 应能同时接入两个独立的 Bot-group 引擎。两台引擎各自完成配对，分别决定连接方向。管理员在第二台引擎确认配对后，第一台引擎上的现有对话应能继续收发。

## 验收条件

1. 在已有单引擎配对的 profile 上升级，恢复已有连接与会话，再配对第二台引擎。重启网关后，两台引擎各自恢复已选方向。
2. 两台引擎使用相同的项目名、成员名和话题编号，同时向同一个 Hermes profile 发出不同消息。各自的会话读取对应历史，群聊回复及已读回执到达原引擎和话题。
3. 分别验证两端都由插件拨号、都由引擎拨号、两端方向相反的情形。单独切换一条连接的方向时，另一条连接上正在进行的对话可以正常完成。
4. 断开、重连或吊销其中一台引擎的配对时，另一台引擎保持可用。来源引擎离线期间产生的回复只能发往原引擎。
