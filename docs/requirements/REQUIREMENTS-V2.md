# 项目中心与协作基础需求

系统以项目为中心组织群聊、话题、需求和任务，统一数据库保存关联数据，以稳定项目身份隔离查询和操作。现行实现见 [工程约定](../engineering/ENGINEERING.md) 和 [项目入口](../engineering/REQ101-PROJECT-ENTRY-2026-10-10.md)。

## 项目与话题

- 项目支持创建、切换、配置、归档和恢复，切换同步更新视图与提交上下文。
- 话题支持成员增删、授权收口及隐藏，隐藏状态与讨论生命周期分别维护。
- 成员变动同步处理未读、发言位和后续唤醒。
- 当前项目入口展示详情与配置，项目列表提供切换和管理。

## 目录与上下文

引擎选择已分配工作区并注入本次项目上下文，宿主按工作区加载 AGENTS.md。work/chat 及话题会话按身份隔离。目录修改影响后续运行，既有任务的来源记录继续保留。

项目约定与文档随 Git 更新，独立工作区通过分支同步。具体存放规则见 [文档与测试报告](../guides/DOCUMENT-STORAGE.md)。

## 验收边界

验证项目范围过滤、目录归属、话题成员变动、收口与隐藏、刷新恢复及宿主上下文加载。使用隔离数据库与运行资源，执行结果归入测试报告。
