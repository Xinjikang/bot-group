# 项目助手的配置、资料准备与原生执行

## 目标

项目类型决定配置、资料来源及交付文档。项目助手理解模板要求和项目已有约定，协助完成新建与详情配置，在创建后发现缺失资料，并准确回答 bot-group 的使用问题。既有个性化结构作为判断依据，无法从资料确定的用户决定保留为待澄清项。

## 功能要求

| 编号 | 要求 | 验收依据 |
| --- | --- | --- |
| PA-01 | 新建向导与项目详情使用一致的字段及模板知识，在各自允许修改的范围协助填写配置。 | 检查草稿、已保存配置及界面实际值，覆盖两处入口。 |
| PA-02 | 创建后按软件、研究、写作、产品原型、算法研发和测试六类模板检查启动资料、文档中的占位及待填写内容；空项目结合目标、输入和产出建立要求。 | 分别提供缺失、默认骨架、已有有效内容和个性化目录，检查缺口、来源及保留结果。 |
| PA-03 | 测试项目确认产品需求及原型的权威来源，整理为模板约定的 PRD 与原型 Markdown；保留来源、版本及未决问题。 | 核对 `docs/product/PRD.md`、`docs/product/PROTOTYPE.md` 的实际正文与原始资料，来源不足时保留明确缺口。 |
| PA-04 | 使用问答依据当前安装的 bot-group 文档和页面入口，说明实际配置、操作方法与生效条件。 | 对照安装文档、实际页面和工具结果，区分检测失败、资料声明与已验证状态。 |
| PA-05 | 助手使用所选 Hermes/Codex agent 的模型、认证、原生文件能力、权限及记忆配置，在独立助手会话中执行任务。 | 核对与群聊 Bot 共用的宿主调用契约、实际路由及配置指纹，检查原生工具调用和产物。 |
| PA-06 | 额外业务工具覆盖必要的项目配置操作与配置页面导航。角色管理、成员启停、角色分配和角色权限复用现有业务接口；操作方法置于系统提示词。 | 检查工具清单、系统指令、数据库实际值及审计记录，覆盖角色、成员与授权操作。 |
| PA-07 | 按指定角色创建 profile 时，读取当前模板对应角色的 SOUL 初始化资料并分配角色。已有 AGENTS.md、SOUL 及项目文档通过原生文件工具修改。 | 核对新 profile 的实际文件、模板来源、角色关联与文件摘要；文档修改后在 HUD 汇报路径及结果。 |
| PA-08 | 长文保存在项目文件中，HUD 展示修改摘要、文件路径、执行阶段和需要用户处理的问题。导航打开当前项目的既有配置窗口并定位相应标签。 | 检查实际文件与 HUD、配置窗口及未保存输入，长文任务保持界面可读。 |
| PA-09 | 已启用助手的项目在创建完成和用户主动要求时立即检查；后台兜底默认间隔一小时，间隔内跳过资料扫描，状态轮询只获取会话状态。 | 可控时间用例核对扫描次数、变化去重、绑定重试及待办保留，检查长任务实际阶段反馈。 |
| PA-10 | 长期记忆使用所选宿主的原生机制；历史项目备注仅保留展示与审计用途。引擎提供的正常项目信息和角色规则保持既有契约。 | 检查实际记忆文件或工具结果及新会话召回；核对项目注入字段、旧备注投影和历史数据。 |

## 配置一致性

PA-C01：同一轮连续修改角色、成员或基础字段时，轮询漏过中间状态仍能同步完整结果。逐步轮询、重复轮询和页面后续全量保存均保留已完成的修改；用户未保存输入按修改前值保护。对象字段顺序差异保持相同语义。

PA-C02：角色、成员和角色权限的版本校验与业务写入属于同一原子操作。人工提交较新版本后，旧助手请求返回 409，人工结果保持有效。业务、审计及 HUD 状态在失败时一并回滚。

PA-C03：历史备注载荷及关联说明从 history、pending_proposal、pending_cards 三条模型回放通道剥离。纯备注待办归档，混合提案继续处理配置和文档，原始历史保留。新的非空 facts 提案被拒绝；迁移后的待办状态可以在配置修订号相同时刷新。

PA-C04：既有 Hermes 会话按原生生命周期更新已缓存的初始系统提示。助手旧绑定先完成未决回执对账，再换代；群聊成员使用现有新会话或工作会话重置流程。发布验收分别核对源码生成内容和实际会话已加载内容。

## 测试隔离与交付验收

PA-T01：数据库、签名、数据目录、宿主 home、工作区端口与测试服务均使用明确归属的隔离资源。测试退出先停止并回收全部后台维护、清扫及事件线程，再恢复进程环境；替换连接池及测试子进程树纳入清理。资源越界和回收失败使验证失败。

PA-T02：未初始化的签名代次 0 在持久授权写入及原生 RPC 前被拒绝，维护入口在开库前拒绝。会话绑定 generation=0 保持既有语义；恢复校验继续拒绝缺失的签名引用代次。

PA-T03：使用两套临时库复现工作区列表、环境恢复、维护中退出、异常清理和连接池恢复。生产替身的数据库内容、主文件和签名文件前后摘要一致，测试线程与进程全部退出。边界用例实际验证数据库、子进程环境和网络端点的越界拦截。

PA-T04：交付分别记录契约回归和真实 agent 验收。六类模板文档、配置操作及原生记忆的模型验收，以所选 agent 的真实文件、数据库结果、记忆产物、来源和 HUD 回报为依据；报告标明范围、被测提交、日志和遗留项。生产服务与用户会话按既有管理员维护流程处理。
