# MCP API 化与宿主运行时配置

MCP 的任务操作统一通过引擎 API，连接配置绑定本次执行。Hermes 与 Codex 启动时接收临时 MCP 配置，存量固定配置由维护者检查和清理。

范围覆盖任务 API 的输入、身份、项目和执行校验，MCP HTTP 转发，共享连接配置，Hermes 独立运行覆盖与清理，以及新成员配置生成。

保持群聊和任务工具参数及协作流程，验证配置优先级、隔离、清理及宿主原生加载。实现见 [MCP 接入](../../mcp/README.md)，设计依据见 [运行时配置](../design/2026-10-20-mcp-config-scope.md)。
