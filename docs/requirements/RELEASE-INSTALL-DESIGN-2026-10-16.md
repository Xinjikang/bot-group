# 本地网页服务安装、启停与升级需求

## 目标

用户在自己的电脑上安装并运行网页服务，默认回环监听，通过浏览器访问。发布源可配置，支持源码资产下载、完整性校验、依赖安装、启动与升级。仓库托管和可见性由发布管理单独决定。

| 动作 | 职责 |
| --- | --- |
| bootstrap | 下载指定版本并核验摘要，建立本地程序目录 |
| install | 检查 Python、建立专用环境、安装依赖、准备配置并自检 |
| start | 就绪检查、启动服务与健康检查 |
| stop | 根据相同配置定位并停止实例 |
| upgrade | 校验、备份、更新、迁移、验证及失败恢复 |

## 约束

配置优先级为命令行、进程环境、本地配置、默认值。程序根与数据根按现行配置解析；默认运行数据位于项目根目录，也支持显式数据目录。子进程使用解析后的绝对路径。

默认本机访问，已配置密码的实例沿用登录机制。前端通过鉴权模式接口判定入口，服务端继续按真实权限校验操作。外部访问配置遵循部署指南。

依赖使用专用环境的 Python 安装，发布清单记录文件归属，源码和安装资产核验 SHA256。发布记录绑定版本与摘要，下载渠道负责发布者可信性。

升级保存用户数据，数据库及配置通过受控迁移更新。缺少旧文件归属清单时中止升级，文件冲突、失败恢复与服务实例隔离纳入验收。

## 验收

覆盖首次安装、幂等安装、配置优先级、自定义数据目录、启停独立、免密与密码模式、正常升级、用户文件保护、迁移失败及恢复。测试使用隔离资源，前后端按各自职责实施。
