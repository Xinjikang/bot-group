# 产品原型设计项目模板

## 目标与角色

模板面向产品部门，使用产品经理、UX 设计师、原型工程师和原型评审员四类角色。产品经理担任项目负责人，管理需求与任务；UX 负责研究、信息架构与体验设计，工程师实现 HTML/CSS/JS 交互原型，评审员独立核对需求与体验覆盖。

## 流程

目标澄清 → 用户研究与体验设计 → PRD 和方案确认 → 原型实现与自测 → 评审与返修复审 → 用户走查 → 产品经理更新文档并验收关闭。

研究材料区分证据与待验证假设。需求变化更新 PRD，体验变化同步 UX 方案，评审绑定文档版本及原型提交。审查与验收结论写入任务节点。

## 成果目录

- `docs/` 分类保存研究、UX、覆盖表、草稿与走查材料。
- `materials/references/` 保存用户资料、竞品截图等参考。
- `ui-spec/UI-SPEC.md` 提供可调整的默认视觉和组件状态规范。
- `outputs/PRD.md` 与 `outputs/prototype/` 保存需求文档和交互原型。

## 接入与验收

接入模板列表、创建导入、角色改名与初始化快照恢复。shared 模式串行协作，worktree 模式由产品经理协调基线、合并与验收。验证生成文件、跨目录链接、既有文件保护、任务闭环、浏览器创建刷新及源码资源打包。现行说明见 [产品原型模板](../engineering/PRODUCT-PROTOTYPE-TEMPLATE.md)。
