# 需求：改善成员发言可读性、点名可见性、停止按钮可见性，支持中英文界面

- 需求 ID：178（bot-group）
- 创建：2026-11-25（bot-36，source_ref thread_id=10156; message_id=13353）
- 设计文档：docs/design/2026-11-25-member-speech-ui-i18n.md
- 状态：open，拆解后按任务推进

## 背景与目标

用户旁观 bot 之间工作讨论时，发言中套话、黑话和过度省略使内容难以读懂；消息中点名对象不醒目，难以一眼看出谁被点、哪条与自己有关；思考气泡旁已有停止按钮但不易发现，用户不知道如何停止正在生成的回复。用户同时要求整个界面支持中文和英文切换。

目标是让第一次进群的人也能做到三件事：读一段 bot 对话说清发生了什么、找到点到自己的消息、停掉一次正在进行的回复；并把界面做成中英双语。

## 范围

四项交付：

1. 成员共用发言规则，写入引擎共用提示词，chat 与 work 两模式全体成员生效；
2. 全界面中英文切换：设置中提供语言选项，仅支持简体中文与 English，选择后立即生效并记住选择；
3. 消息正文的 @ 点名加粗，背景透明，点到当前用户的消息显示对应语言标记；
4. 思考气泡旁现有停止按钮的可见性和点击区域。

范围外：中英以外语言、已发送消息的翻译（保留原文）、管理界面之外的额外语言支持。

## 方案依据

发言规则原文由用户逐字给出（thread_id=10156; message_id=13352）：
「成员之间用简洁、自然的工作语言，直接说具体的事。不甩词，不说套话，不说黑话，不省略必要的文字，确保意思准确。用到专业词时，让旁观者从上下文就能读懂。」

其余三项的技术落点、词表机制与任务依赖见设计文档 docs/design/2026-11-25-member-speech-ui-i18n.md。

## 验收标准

1. 引擎共用提示词包含发言规则原文，逐字核对一致；chat 与 work 两种模式均能加载该规则。
2. 从真实 bot 对话中选一段，请初次接触的人读后能说清发生了什么、需要谁做什么。
3. 用中文和英文分别检查聊天、设置、管理页面：切换立即生效，重新打开仍记住选择，已发送消息原文一致。
4. 新用户在无提示下找到点到自己的消息，并通过思考气泡旁的现有按钮停掉一次正在进行的回复。
