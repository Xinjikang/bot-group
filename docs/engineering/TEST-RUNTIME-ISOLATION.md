# 运行时单元测试隔离

涉及数据库、会话、签名或连接池的单元回归通过 `scripts.run_isolated_tests` 执行。命令和前置条件见 [测试索引](../../scripts/TEST_INDEX.md)。真实模型与原生宿主验收沿用各自脚本的显式资源配置。

## 资源边界

运行器在导入测试模块前创建独立 SQLite 默认路径、数据目录、附件目录、Hermes/Codex home 和合成认证配置，清除继承的运行时与模型环境。临时目录和测试子进程的默认路径均归属于同一运行沙箱。报告单独写入 Git 忽略的项目 `reports/tests` 目录。

Python 审计钩子在 SQLite 连接、文件写入、套接字绑定/连接及子进程创建前检查资源归属。数据库限定在沙箱内；文件写入限定在沙箱或报告目录；监听使用随机回环端口，连接限定为当前进程实际持有的监听端点；子进程的数据库、数据目录和宿主 home 必须在沙箱内。自建引擎的端口先由父进程随机分配，再核验该子进程实际拥有监听后放行请求；每个用例结束检查并回收遗留测试子进程。审计钩子的作用域为测试 Python 进程，子进程通过独立环境和受控入口获得测试资源。

`isolated_runtime` 为每个夹具设置独立路径、清空已加载签名状态，并拥有独立连接池。默认 opener 返回离线状态，具体 RPC 用例显式提供模拟连接。`resume` 创建的替换池一并登记。工作区服务和浏览器配置使用夹具持有的随机回环端口，数据目录落入夹具目录；可用性检查限定到这些端口。连接池维护、清扫和事件线程全部保存句柄；夹具退出依次执行 stop、join 和连接关闭，随后恢复模块状态与环境。线程回收超时打印错误并以退出码 70 终止测试进程，保持失败状态。

运行结果包含测试选择、失败/错误数、后台维护错误、残留线程及越界拦截记录。后台维护错误或残留线程使运行结果失败；用例自身断言预期的拦截行为。

## 持久签名保护

`auth.signing_keys()` 的代次 0 继续用于未初始化进程的临时凭据。持久会话授权的 grant/configure 入口要求正整数签名代次，检查先于数据库修改、提交及原生 RPC。维护入口在打开数据库前检查该条件。会话绑定自身的 generation 0 保持既有语义。

恢复校验继续要求所有引用的签名代次存在，并校验密钥摘要。未知代次引用通过既有恢复错误报告，维护者依据现场证据修复对应授权状态。

## 验证证据

污染回归使用独立的“生产替身”与测试数据库。替身含签名代次 20、pending_generation 为空的合成授权和匹配的密钥文件。用例执行实际工作区列表请求、维护线程执行中退出、异常清理和多次 resume，比较替身数据库内容、数据库文件及签名文件的 SHA-256，并确认所有测试线程已退出。另直接验证数据库/子进程环境越界与未归属端点被拦截、未初始化签名的持久写入被拒绝，以及未知引用代次仍使恢复失败。
