# 前端刷新范围

更新时间：2026-10-26。

数据请求和 DOM 更新分别决定范围。SSE、轮询和用户操作可以获取最新数据；数据相同直接结束，数据变化只修改对应区域。当前消息视图内，保留未变化的消息正文、原生选区、回复编辑器和图片节点。初始化、切换项目或话题时，才替换整段消息视图。

## 触发与更新范围

| 触发 | 数据入口 | DOM 更新范围 |
| --- | --- | --- |
| 思考正文/工具调用新增、气泡展开或折叠 | `pollReasoning`、气泡点击 → `renderThinkBubbles` | 按 bubble key 找到对应气泡，比较内容签名；更新头部、状态和变化的步骤。已有步骤按 entry ID 保留，新增步骤追加。正常内容更新直接进入气泡，跳过消息列表渲染入口。 |
| 新运行、运行结束、回复绑定、气泡显示位置变化 | `wake.spawned`、`wake.finished`、reasoning 工具结果 | 结构签名变化时对齐气泡位置；气泡绑定正式回复时复用原气泡，更新对应消息的思考入口。其他消息正文继续使用原节点。 |
| 新消息 | `message.new` → `refreshMessages` | 消息按 ID 对齐，增插新行；对应话题条数随之变化。既有消息正文继续使用原节点。选中文字期间新消息照常出现。 |
| 撤回或消息字段变化 | `message.retracted`、消息查询 | 更新对应消息的内容与标记；同一消息的其他稳定区域和其他消息节点按差异保留。被撤回的正文按业务规则更新。 |
| 加载更早消息 | 顶部滚轮 → `loadOlderMessages` | 插入旧消息，补齐对应话题分组；保留原消息节点和可见消息的像素位置。 |
| 话题标题、隐藏、关闭或结论变化 | `thread.*` → `loadThreads` | 更新左侧话题卡片、当前话题标题和输入可用状态；总览对齐受影响的分组标题、可见性、结论及回复入口。 |
| 未读数量、成员信息 | `loadInboxSummary`、`loadMembers` | 更新话题未读标记、成员选择区域；这些请求本身不替换消息正文。 |
| 任务变化与任务轮询 | `task.updated`、`loadTasks` | 更新右侧任务区域；关联话题通过 `loadThreads` 检查其投影变化。任务过程弹窗按打开、手动刷新和关闭操作更新。 |
| 图片加载完成、打开预览 | 图片观察器、图片点击 | 更新对应图片或预览弹窗。节点对齐后挂载附件，同一容器中的已加载图片保持原位。 |
| 初始加载、项目/话题切换 | `boot`、`selectProject`、`selectGroup`、`selectThread` | 增加 `messageView`，替换当前消息视图。异步响应仍按视图编号过滤。 |
| 网页重启或升级成功 | 操作回执与 `/health` 新实例校验 | 清除维护监控记录，自动刷新当前整页，重新加载 HTML、脚本、样式及连接；失败保留当前页面显示结果。 |

## 消息区实现约定

- `renderThinkBubbles` 区分内容变化与位置变化；内容更新只遍历气泡并更新签名变化的项。
- `renderMessages` 负责消息和结构变化。同一 `messageView` 使用 `syncMessageChildren` 对齐消息 ID、话题 ID、bubble key、entry ID；新视图使用 `replaceChildren`。
- 原生选区依赖真实文本节点。相同内容保留原节点；气泡移动至回复位置时，浏览器可能重置 Range，只有原端点及文本仍有效时才恢复选区方向和偏移。
- 回复编辑器独立持有草稿、焦点、输入选区和输入法组合态。对齐过程保留该节点；输入法组合期间沿用已有延迟结构更新约定。
- 仅在原本贴底且没有消息选区、鼠标按压或编辑焦点时自动跟随底部。阅读历史时保留可见内容的位置；气泡内部滚动单独保存。
- 用户选中文字期间，思考内容和新消息继续显示。鼠标事件和 `selectionchange` 不承担暂停/恢复数据刷新的职责。

## 验证

`python -B scripts/verify_message_selection.py` 使用无头 Chrome 和完全拦截的本地夹具，无服务、数据库和 bot worker。覆盖正反向拖选、按下到拖动之间刷新、松开后选区、跨消息选区、气泡文字选区、内容更新跳过消息列表入口、新消息即时显示、历史分页锚点、撤回、话题标题、回复绑定、气泡折叠、编辑器草稿/焦点及视图切换。

同时运行消息分页、回复编辑器、思考生命周期、运行存活、话题分组、项目视图、隐藏话题和点对点思考顺序的 Node 回归，以及现有图片浏览器回归。前端静态文件刷新页面后生效。
