# 项目成员移除

## 界面与范围

项目详情“成员与目录”卡片保留启停、角色选择及工作区入口。更多菜单提供编辑 profile、重置会话和移出项目；编辑项说明 profile 配置影响共用它的项目，重置项沿用已有会话状态，移出项放在分隔线下并使用危险色。菜单支持键盘导航、Escape、外部点击关闭、滚动关闭及视口边界避让。

移出前显示取消、重新检查和移出项目按钮。存在阻塞事项时禁用提交，列出具体事项和处理入口：项目负责人进入基本信息；任务和需求打开对应详情；话题进入讨论；运行状态通过现有停止操作确认并处理。取消保留成员状态。操作成功刷新成员卡片、候选列表和话题，移出的成员可通过添加成员重新加入。

## 接口与检查

话题成员管理通过 `GET /members?project=<话题所属项目>&enrolled_only=true` 获取显式入组名单，覆盖启用与停用成员。`enrolled_only=true` 必须提供非空项目；省略该参数保留全局身份花名册语义，`active_only=true` 可进一步限制启用成员。项目外身份和已移出成员从列表排除。弹窗每次打开和增删后重新读取，旧话题的异步结果丢弃；读取失败显示重试入口。已停用成员保留状态和移出话题入口，加入操作需先在项目中启用。

- `GET /projects/{name}/members/{profile}/removal`：管理员读取 `can_remove` 和 `blockers`，预检查保持状态原样。
- `DELETE /projects/{name}/members/{profile}`：管理员提交移除，事务内重新检查；职责或运行状态冲突返回 409，详情携带可显示的 `message` 和 `blockers`。已离开成员返回 404，内置用户保留。
- 阻塞条件：已配置的项目负责人；成员作为下一执行人或领取人的未完成任务；进行中的需求拆解；成员负责收口的开放话题；本项目该成员正在运行或尚待确认退出的进程/唤醒；正在切换的会话。

检查使用实际项目数据。角色名称与任务阶段文本由项目配置、协作规则决定。

## 状态与并发

移除只解除指定项目的成员关系及直接授权，从该项目话题参与名单移除成员，过期该成员的待收消息、取消排队唤醒并清除执行窗口。成员占据的话题发言位在同一事务中推进；唤醒入队支持由外层事务统一提交。失败回滚包括成员关系、授权、话题、收件箱和队列状态。

执行顺序与进程启动保持一致：工作区锁、会话切换锁、SQLite `BEGIN IMMEDIATE`。排队任务领取的成员条件继续生效，实际移除再次检查当前状态，防止预检查结果过期后提交。

全局 Bot/profile、其他项目成员关系、历史消息、任务记录、工作目录和工作区登记保留。成员重新加入后重新配置角色与权限；原工作目录可继续通过工作区入口管理。移除记录写入 `project_config_events`，动作名为 `member.remove`。

## 验证与部署

单元与 HTTP 回归：`scripts/test_project_member_removal.py`。真实 Chrome 交互：`scripts/test_project_member_removal_browser.py --evidence <报告目录>`。包括取消、职责阻塞、运行检查、权限撤销、事务回滚、跨项目隔离、重新加入、窄屏菜单及页面刷新。

后端更新后重启引擎，浏览器 Ctrl+F5 加载前端资源。
