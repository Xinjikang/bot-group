# 导入项目：角色与协作规则共同确认

当前 [七步向导](PROJECT-SETUP-WIZARD-2026-10-14.md) 在第四步编辑协作规则；最终确认前按角色、授权和目录模式核对正文。

第三步保护模板指定的负责人角色，其余角色按向导规则调整；删除角色清空对应成员分配。第四步按所选模板生成规则草稿，显示当前角色与权限供人工核对。返回修改角色、权限或协作方式会清除确认勾选并保留草稿；换目录或模板重新生成。最终确认的备份与保护规则见 [向导迁移](PROJECT-SETUP-CLEANUP-2026-10-15.md)。

AGENTS.md 独立于基础文件补齐开关。最终预览包含正文差异和备份路径，确认导入后才写文件。现有文件未编辑时保持原始字节（包括 CRLF）；修改时先保存原文到 AGENTS.md.backup-<原文件 SHA256>，再原子替换。其余已有文件仍保留。超出 128 KiB 或非 UTF-8 的规则文件需先在本地整理，避免截断保存。

接口的 agents_edit 包含 content 和 original_sha256；plan_hash 绑定完整配置、原文件状态、正文、差异与备份。原文件变化拒绝预览/提交。数据库事务失败会恢复本次替换的原文件并清理本次新增文件；若替换后又被外部修改，则保留外部修改和原文备份。旧客户端未传 agents_edit 时继续原有保留/补齐行为。

测试使用临时项目与隔离数据库，覆盖规则生成/修改、备份、冲突、失败回滚、角色变化后草稿核对，以及真实 Chrome 向导和窄屏布局。
