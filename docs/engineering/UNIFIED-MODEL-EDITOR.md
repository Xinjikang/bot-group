# 统一模型配置入口

2026-10-11：成员卡片保留“编辑”按钮，删除“项目模型”按钮及独立弹窗。“模型与供应商”标签内增加“应用到全局”复选框。

“应用到全局”复用项目权限复选框的主题样式：14px 圆角描边、主题背景、金色选中态与勾形标记，并保留键盘焦点轮廓及禁用反馈。浏览器用例覆盖深浅主题的选中/未选中状态。

- 从项目成员卡片打开时默认未勾选，展示本项目覆盖后的有效模型、供应商和推理强度。修改保存到项目成员模型接口；没有修改的继承字段保持空覆盖，继续跟随全局。
- 勾选后将三个字段保存到该成员的全局配置，并清空当前项目这三个字段的覆盖。其他项目的独立覆盖保持原样。
- 切换复选框保留当前输入。描述、SOUL/AGENTS 与环境变量仍按已有全局成员配置规则保存；仅修改项目模型时跳过全局配置写入。
- 从全局花名册打开时，“应用到全局”保持勾选且禁用，因为该入口没有项目范围。
- 复用现有两个带 revision 校验的接口。涉及全局及项目时依次保存；全局成功而项目失败会明确显示部分完成、保留草稿，并使用更新后的全局 revision 支持重试。两接口之间不提供跨文件/数据库原子事务。

验证：两套真实 Chrome 夹具测试 `test_project_models_browser.py`、`test_codex_config_browser.py`，以及项目模型和双宿主 profile 配置单元测试。全部请求及配置使用隔离数据；生产模型配置未作修改。
