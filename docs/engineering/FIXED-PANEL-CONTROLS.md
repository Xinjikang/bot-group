# 固定面板操作入口

面板布局约定：

- 隐藏话题查看/收起开关移到左侧话题栏底部，作为滚动列表的兄弟元素；列表单独滚动，开关始终可见。有隐藏话题时显示数量，没有时隐藏。原有展开/收起状态规则保持。
- 任务过程及需求详情将刷新、关闭按钮放在独立的固定操作栏；标题与正文放进单独的滚动区域。长内容滚动时按钮始终可操作，标题随正文滚走。
- 任务面板的归档需求开关保持原样。

验证：`test_fixed_controls_browser.py` 覆盖 100 个话题、长详情、1280/390px 布局和真实关闭点击；`test_hidden_topics.cjs` 与 `test_requirement_details_browser.py` 验证已有功能。测试使用合成数据，无生产写入。

前端静态资源更新后刷新页面生效。
