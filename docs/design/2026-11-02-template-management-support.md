# 模板管理支持与重复返修话题触发（req#141）

日期：2026-11-02。项目：bot-group。

## 背景

协作中出现执行成员反复返修、管理者支持不足、审查口径和帮助效果缺少持续跟踪。模板已有任务定义、审查交付和协作升级规则，本轮以新增具体管理支持行为、减少重复提示为目标。基线为话题 10123 消息 10223 完整方案，并纳入 10225、10229 对审查四项的全段语义核对与去重说明；用户 10230 明确授权收口并建需求。

## 改动范围

### 1. manifest 角色职责增量（6 份 manifest.json，仅追加）

仅追加 `roles[].responsibilities`，原职责和 `permissions` 保留，通过现有 ROLE_TABLE 渲染呈现，删除建议中的独立软件职责追加句。

| 模板 | 角色 | 增量 |
| --- | --- | --- |
| software | owner | 统筹整体效率、跟踪协助解除阻塞 |
| software | architect | 具体可验证的技术支持 |
| software | reviewer | 可执行返修指导 |
| writing | editor | 统筹整体效率、实质支持、跟踪解除结果 |
| writing | proofreader | 修订指导 |
| algorithm | lead | 统筹整体效率、实质支持、跟踪解除结果 |
| algorithm | reviewer | 返修指导 |
| testing | lead | 统筹整体效率、实质支持、跟踪解除结果 |
| testing | reviewer | 修订指导 |
| research | lead | 统筹整体效率、实质支持、跟踪解除结果 |
| research | verifier | 补证与修订指导 |
| product-prototype | pm | 统筹整体效率、实质支持、跟踪解除结果 |
| product-prototype | reviewer | 返修指导 |

### 2. AGENTS.md.tmpl 四条管理行为（6 份）

在完整角色章节之后插入四条管理行为：保护整体效率、主动提供帮助、让返修能够执行、跟踪帮助效果。内容包括复核自身判断、资料/权限/资源实际可用、最小验证及判据与证据、具名协助、可独立执行复验步骤、帮助结果原节点记录。

插入点：software 开发流程前；writing/research 工作流程前；algorithm 研发流程前；testing 测试依据前；product-prototype 协作流程前。原派工清单、单列重复阻塞升级段、软件追加职责句均不引入。

### 3. 审查段补全

问题位置、依据、预期与实际、影响集中维护在原审查段，按完整语义只补缺项，管理第 3 条引用。software 已有判断理由/验证依据，补预期与实际并关联判断依据。位置：software 审查交付、writing/research 工作流程核验失败段、algorithm 评审与交付、testing 评审与资源、product-prototype 需求变更与评审标准。

### 4. wake.py L2 话题触发替换（两处）

`_WORK_SYSTEM_PROMPT` 第 5 条与 `_CHAT_SYSTEM_PROMPT` 第 6 条的 L2 括号同步替换为：

> 需多人讨论，或同一问题反复返修仍未解决时，建话题拉相关成员，结合已有证据和尝试记录明确原因、解决路径与协助分工→结论落库→收口。

其余升级链（L1 自协商、L3 项目负责人仲裁）保留，原草案派工清单和重复阻塞独立第 5 条删除。

## 验收

1. 六份 manifest 角色职责仅增加约定支持职责，原职责和 permissions 保留，ROLE_TABLE 实际渲染能呈现相应角色新增内容。
2. 六份 AGENTS.md.tmpl 在约定位置包含已确认四条管理行为；新段落提供具体支持、可执行复验及效果跟踪，原派工清单、单列重复阻塞升级段、软件追加职责句均不引入。
3. 各模板审查段整体覆盖问题位置、依据、预期与实际、影响，同义已有要求保持并消除无意义重复；专业字段、task_log 与交接顺序保持。
4. WORK/CHAT 系统提示词两处 L2 均包含重复返修触发及证据/原因/解决路径/协助分工，其他升级链与执行机制保持。
5. 按测试索引运行与改动匹配的模板加载/渲染及提示词回归，核验角色映射、模板结构和权限未变化；按项目约定提交必要文档、结果和审查验收节点，报告记录被测提交及遗留项。
6. 变更保持范围边界：原有项目配置、SOUL 及其他三项议题不被实施；按项目流程完成开发自测、独立审查、架构验收和 manager 独立验收。
