# Hermes 网关连接复用与全局状态

## 范围

引擎统一选择 Hermes 子进程或网关 WS 模式。网关模式复用已建立的连接，使用业务空闲 600 秒回收策略。顶栏只展示一个全局只读状态，子进程模式隐藏该组件。模型服务故障保持在对应执行的错误反馈中。

## 连接契约

业务连接优先通过本地 control identify 发现运行中的网关，验证当前安装提交、profile、实例身份、协议和能力，取一次性票据建立 WS。快速发现和握手共用 5 秒预算；确认网关缺失后才调用官方 gateway ensure，并将并发启动串行合并。权限、身份、协议和版本异常直接反馈。版本变更阻止新执行接入旧实例，管理员负责重启。

WS 按原生票据的 profile 身份隔离并复用。请求按 JSON-RPC ID 分发；事件按 session ID 路由到使用者。使用者释放连接租约时，释放其会话订阅；最后一个使用者离开会话后调用 session.detach，保证下一次 resume 重新读取原生配置。RPC 传输错误交还现有执行账本核对，业务写请求保持单次发送。

轻量心跳检测连接状态。心跳、页面状态读取与只读历史查询保持业务空闲时间。无使用者、无持久未决执行，且业务空闲达到 600 秒时关闭 WS。未决执行包括运行、取消、结果未知及尚待清理的执行，以及助手尚待核对的 admission。意外断线做有界重连，保持原提交身份。引擎退出关闭所有连接并阻止迟到连接进入池。

## 展示契约

右上角在引擎连接状态旁展示状态点与文字，无按钮、点击详情和影响范围。状态为待连接、连接中、已连接、离线、连接异常、需要重启、状态未知。主动空闲释放显示待连接。状态由引擎的连接管理器提供，接口读取保持被动；前端失联或结果过期显示状态未知。采用现有主题变量并验证桌面和 390px 窄屏。

## 验证

隔离验证连接复用、并发连接与启动去重、profile 身份隔离、请求和会话事件分发、订阅释放、空闲回收、未决执行保护、断线与原回执恢复、版本变化及关闭竞态。HTTP 验证只读状态和身份限制。浏览器验证模式显隐、全部状态、断连过期及深浅主题布局。复用网关、助手、只读会话和停机回归。
