# 项目配置职责划分

既有项目核查发现：数据库中的启动目录、AGENTS.md 中的目录表、Git worktree 注册及成员工作目录可能出现差异。主目录与 worktree 还可能载有不同版本的规则。目录选择应形成可验证的统一运行契约。

具体环境盘点保存在项目主目录测试报告 `project-configuration/2026-09-23/REPORT.md`。当前实现见 [项目配置](../engineering/PROJECT-CONFIGURATION.md)。

| 信息 | 负责层 |
| --- | --- |
| 稳定项目身份、成员资格、工作区分配、启停与归档 | 引擎配置及服务端校验 |
| 宿主身份、模型、认证和宿主原生设置 | 宿主配置；引擎按已授权入口管理 |
| 业务背景、工程规范、分工、分支及验收流程 | 项目 AGENTS.md 与版本化文档 |
| 话题、任务、执行、心跳与消息状态 | 引擎运行数据 |

启动目录与项目归属须在工作开始前确认，提示词展示实际分配结果。worktree 文档随分支提交和合并，交接引用路径与提交。目录及成员配置变更经相应入口执行，普通启动沿用已保存权限。

权限决定可执行操作，角色描述项目分工。归档和目录清理检查未完成工作及运行资源，detached HEAD 按项目审查流程判断。
