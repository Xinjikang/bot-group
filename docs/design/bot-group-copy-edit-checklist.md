# 提示词、项目约定与角色参考的维护边界

引擎公共提示词描述工具协议、身份、模式限制和通用执行边界；项目 AGENTS.md 描述角色、协作流程和交付要求；SOUL 参考描述专业偏好与表达习惯。

公共规则维护单一来源，work/chat 模式组合各自规则。项目名、目录和本次任务属于动态上下文，静态提示词保持稳定。

项目规则由宿主加载到上下文。公共提示词、工具说明和角色参考直接描述操作、参数及专业职责，省去规则来源和服从规则的重复声明；启动入口按任务需要引导查阅专业文档。规则文件的加载、同步、编辑接口与文档导航保留准确文件名。模板修订随新建、导入或再次引用生效，已有项目文件和人格配置由维护者另行更新。

任务节点记录成果、审查意见、验收结果和具体下一位成员。项目约定依据角色分工和授权选择具体接手人，并确认其角色符合当前阶段要求。负责人协调技术障碍，用户决定范围、优先级、费用及生产外部动作。

成员查询条件由引擎通用提示词维护：需要确定协作成员且现有信息不足时，调用 group_list_members 查询；任务交接前确保已取得接手人的有效 profile 和对应角色信息。项目模板保留角色分工与交接要求，工具说明维护参数、返回字段与校验契约。

各模板依据用途维护成果目录，具体规则见 [文档存放约定](../guides/DOCUMENT-STORAGE.md)。

## 修改检查

- 文档直接说明行为、技术依据、约束与操作步骤，注释和工具说明采用相同边界。
- 改动角色名称时检查模板变量、权限、SOUL 引用和预览输出。
- 改动公共提示词时验证静态组成、模式限制、消息交接和任务节点行为。
- 模板升级同步 manifest，保留既有初始化快照恢复能力。
