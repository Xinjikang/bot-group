# MCP 配置职责与运行时注入

引擎为每次启动的 Codex / Hermes 成员临时注入 bot-group MCP 配置，负责连接地址、身份和执行上下文。用户自行管理宿主中的其他 MCP 接入。

运行配置按本次执行隔离，结束后清理临时覆盖。成员创建和发现保留宿主已有配置，MCP 通过引擎 API 操作任务，数据库路径由引擎管理。

临时注入使连接配置与本次执行绑定，减少固定配置遗留、重复注册和跨项目串用。Codex 使用运行参数，Hermes 使用每次执行的配置覆盖，实际实现见 [MCP 接入说明](../../mcp/README.md)。

旧宿主配置中的固定条目由维护者检查和清理。验证覆盖配置优先级、运行隔离、退出清理与原生加载，具体命令见 [测试索引](../../scripts/TEST_INDEX.md)。
