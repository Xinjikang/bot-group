# Hermes 授权卡片

## 范围

将 Hermes 网关执行中的普通命令与编辑审批呈现在对应项目、话题的用户界面。审批规则、可选权限范围及最终执行由 Hermes 决定。密码、sudo、澄清问题和旧版 CLI 保留原生交互。

## 数据与权限

仅从 bot-group 的 hermes_executions 账本取得宿主、会话及执行轮次。后台执行观察器通过 session.resume 获取 generation-bound prompts，保存已脱敏的审批快照；快照过期、连接异常或执行终止时禁止操作。HTTP 读写接口仅允许管理员用户，Bot 凭据无法读取或审批。客户端仅提交执行 ID、请求 ID、轮次和选项，宿主路径与会话 ID 均由账本解析。

提交时重新读取当前账本和 Hermes 快照，核对执行轮次、请求存在性与可选范围，然后调用 approval.respond。相同执行的本地提交串行，双端竞争以 Hermes 的 resolved/already_resolved 为权威。提交结果未知时禁止自动重放，后续仅查询状态。

## 界面与恢复

授权区位于消息列表与输入框之间，展示 Bot、项目/话题、执行内容、原因及 Hermes 提供的选项。总视图显示所选项目的待审批项，具体话题只显示本话题。长期授权选项二次确认。关闭页面或切换项目保持原生审批等待；恢复后从后端快照重新显示。后台每轮执行观察同步快照，前端定时查询；Hermes 已处理的请求随快照移除。失败保留明确提示，提交中禁用按钮。

消息栏可用宽度小于 320px 时，授权区改为页面底部浮层，两侧留 12px，最大高度为视口的 45%，内容独立滚动。该组件响应消息栏实际宽度，兼容窄屏及侧栏调整；现有主布局保持原有规则。

## 验证

覆盖管理员与 Bot 鉴权、项目/话题隔离、执行终止、轮次变化、非法选项、重复提交、原生端先处理、断线和未知结果。真实 Chrome 检查深浅主题、390px、刷新恢复和错误状态。原生 Hermes 验证使用隔离 home/会话和合成审批内容，禁止审批生产任务。
