# DSH 0.2.2 启动兼容

POSIX 凭据复制在写入前将私有目录限制为 0700，目标文件通过 O_CREAT | O_EXCL 和 0600 创建。目标冲突直接失败，写入失败清理本轮副本。Windows 继续核验目录和文件 DACL。

DSH 0.2.2 起使用 headless 原生参数 `--permission-mode auto --approval-policy never`，原生运行器在插件加载完成、会话创建完成后选择 Auto，再提交任务。适配器在 turn/start 记录预设，并在工具执行前核验当前预设，能力失效返回原生 deny 决策。纯文本轮次也产生预设证据。旧版保留 session/created 启用路径。

版本读取覆盖独立 CLI 包、npm 包装入口和桌面 app.asar。未知版本沿用旧适配器及能力证据门禁。唤醒和项目助手共用版本判定、命令构造与适配器生成逻辑。版本比较表示启用路径选择，具体构建的完整兼容性以原生验证为准。

回归包含私有权限创建、目录限权失败、竞争文件保护、新旧版本选择、续跑参数、实际 JavaScript 事件时序、零工具轮次、Auto 失效阻断和项目助手入口。命令见测试索引。
