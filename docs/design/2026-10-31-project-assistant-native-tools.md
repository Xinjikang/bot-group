# 项目助手复用宿主原生执行能力

## 职责与工具

项目助手使用用户选定的 Hermes 或 Codex agent，在独立助手会话中完成资料查找、文档编写和结果检查。bot-group 提供项目上下文、工作目录、配置业务接口与 HUD。Hermes 选用原生 file 工具集（search_files、read_file、write_file、patch），Codex 保留原生命令执行与补丁编辑。宿主模型、提供方和身份来源沿用所选配置，工具选择覆盖仅作用于助手会话。

额外提供一个 MCP 工具 update_project_config，绑定当前助手会话及项目，支持创建草稿与已建项目的通用配置。配置更新通过服务端业务校验、乐观版本检查、项目状态检查及目录授权同步；工具凭据只在当前有效助手执行中生效。用户明确指令授权的工作直接执行，结果在 HUD 汇报；主动检查只提出缺项与建议，需要业务判断时集中询问。

文档内容由宿主文件工具直接修改，工具执行结果和实际文件作为完成依据。HUD 显示文件路径、修改摘要及待确认事项；文档全文保存在项目中。既有确认提案保留兼容处理，新增文档任务使用原生工具。

## 检查与上下文

创建完成和用户主动要求时立即检查。后台兜底间隔为一小时，周期内直接跳过项目资料扫描；周期到达后先比较文件元数据与配置，存在变化时排队。页面状态轮询只读取会话状态。项目正文通过原生工具按需阅读，模板规则、资料入口和使用文档来源注入上下文。

## 验收

单元验证覆盖受限 MCP 清单、会话/项目/执行权限、草稿和详情配置更新、版本冲突、宿主启动参数与低频扫描。实际验收使用用户配置的模型与 agent，在隔离项目中读取输入资料、生成及修改文档、调用配置工具更新配置，并核对文件正文、保留内容、来源与数据库实际值。记录模型路由、宿主配置指纹、产物、工具调用和 HUD 结果。模拟返回仅用于回归，交付验收以真实 agent 的实际产物为准。
