# 项目维护 HUD

范围与验收见[项目助手需求](../requirements/2026-10-31-project-assistant.md)，执行方式见[宿主原生工具设计](2026-10-31-project-assistant-native-tools.md)。用户为顶栏常驻 HUD 选择维护 Bot。创建草稿与正式项目共用维护记录；待答问题、配置提案与展示历史持久保存，模型上下文按会话生命周期换代。长期记忆由所选宿主管理。

## 交互

HUD 提供对话与待办标签。普通交流显示回复，问题和兼容配置提案显示独立卡片，使用问答给出操作说明。原因默认折叠，切换标签保留输入和阅读位置，具体主题、展开及窄屏规则见 [UI 规范](../ui-spec/UI-SPEC.md)。更多菜单提供项目切换、设置及已有历史备注入口。

HUD 设置选择已有 Bot 或创建 profile；默认 AI 用于后续预选，用户逐项目启用维护。创建成功后使用提交回执绑定正式项目，重试保持幂等。助手可以打开当前项目的既有配置窗口并定位标签，保持该项目未保存的输入。

用户直接要求修改文档或配置时，助手调用原生文件工具或项目业务工具执行，核对实际结果后在 HUD 汇报路径、摘要和生效条件。长文保存在文件中。兼容配置提案继续支持确认、暂不处理和调整要求，向导最终提交沿用创建校验、文件生成和工作区准备流程。

## 状态与决策

引擎提供当前阶段、配置快照、模板规则、项目资料元数据、待答问题及近期维护对话。模板提供用途与检查依据，目录映射结合实际项目约定；空项目先明确目标、输入与产出。原生文件工具按需读取正文，助手标明实际依据、读取边界、资料缺口和待澄清决定。

已启用助手的创建完成、用户输入及显式重试立即执行。后台兜底默认间隔一小时，间隔内跳过资料扫描；状态轮询只获取会话状态。到期先比较配置和文件元数据，变化触发合并排队；同一维护会话保持单次运行。失败保留输入与待办，显式重试。待处理问题或提案按既有会话规则保留。

配置工具记录有序修改步骤，前端补齐漏过的更新并保护本地编辑。角色、成员和权限的版本检查、业务写入、审计与 HUD 状态共用原子事务，冲突返回 409。历史备注的模型投影、待办归档及旧会话换代遵循 [HUD 工程契约](../engineering/PROJECT-HUD.md)。

## 运行与权限

助手运行采用独立会话，模型、认证、宿主权限、原生文件及记忆能力沿用所选 Hermes/Codex 配置；群聊协作由项目成员承担。额外业务入口为项目配置和配置页面导航，工具操作方法在系统提示词中维护。项目配置写入校验当前会话、项目、执行凭据和版本；维护 HTTP 接口沿用管理员权限。

原始项目材料作为数据处理，检查结果保留未知状态。原生文件操作遵守宿主授权及当前工作目录约定，服务端资料探针使用有界读取与路径保护。运行进度使用原生工具及宿主事件，重启恢复与未知回执沿既有执行生命周期对账。

测试使用独立数据库、签名、宿主目录及随机回环端口，线程和测试子进程退出后恢复环境。边界拦截、持久签名保护与实际验收见[运行时测试隔离](../engineering/TEST-RUNTIME-ISOLATION.md)。
