# 项目助手：有依据的检查与清晰的确认

范围与验收见[项目助手需求](../requirements/2026-10-31-project-assistant.md)。执行与记忆沿用[宿主原生工具设计](2026-10-31-project-assistant-native-tools.md)。

## 目标与边界

助手解释项目用途、结构、配置缺口与文档冲突。每条判断区分实际检测、文档声明、用户决定和待核实内容；检测失败保留未知状态。引导以普通用户可理解的现状、影响和下一步为主，文件路径与技术来源放在必要的证据说明中。

模型专用指令通过 Hermes 会话系统提示和 Codex developer_instructions 注入，项目资料单独作为用户输入。当前执行能力见[宿主原生工具设计](2026-10-31-project-assistant-native-tools.md)：原生 agent 完成文档读写，项目配置通过单一业务工具处理。Git 和 CodeGraph 配置变更继续由专用流程完成。

## 项目理解

优先读取 README、AGENTS、文档索引和工程入口，再读取索引链接与其他文档；保留目录与源文件结构、读取范围和截断标记。检查文档链接指向的文件是否存在。版本说明、模板和代码片段只表示对应资料中的声明，正式发布状态需要独立证据。

固定检查包括项目目录、Git 仓库归属、远程配置、工作区修改、CodeGraph 安装与索引状态、成员及职责、工作区资源和文档链接。外部程序使用固定参数、超时和输出上限，结果不包含认证信息。CodeGraph 为可选能力，结合实际项目约定决定是否需要用户处理；工具不可用与项目明确停用分别表达。

检查结果参与项目变化摘要；每次实际对话重新取样。目录和文档扫描设定明确上限，未覆盖的内容标为待核实。文档语义矛盾由模型列出双方来源，自动探针只保证自己验证过的事实。

工作区资源以专用表中的持久配置为依据，按成员实际工作目录归并共享关系。资源读取沿用页面的目录选择规则；保存版本、端口和数据目录共同提供给模型。默认建议与已保存配置分别表达，目录归属缺口保留待核实状态。

## 引导与确认

已读取且无矛盾的资料直接用于回答。缺失的用户决定通过问题澄清。长期约定使用所选宿主的原生记忆流程，明确项目适用范围，并依据实际记忆结果汇报。历史项目备注用于展示及审计，模型回放对历史、提案和卡片剥离备注载荷。

兼容配置提案显示修改对象、当前位置、当前内容、建议内容与生效时点，当前值由引擎提供，无变化项移除。用户可确认、暂不处理或继续输入调整要求。用户直接要求修改时，助手使用原生文件工具或配置业务工具执行并在 HUD 汇报实际结果；长文保存在项目文件中。连续配置同步保留完整步骤，版本冲突通过原子校验处理。

待处理提案持续阻止空闲超时重置。追问及逐条讨论保留完整提案，每轮作为独立上下文提供；确认或明确点击“暂不处理”后重新计算空闲时间。新的提案替换原提案并继续阻止超时重置；直接修改向导草稿仍使对应旧提案失效。

验收覆盖普通交流、解释术语、缺少 Git 远程、CodeGraph 未安装/索引过期/检测失败、文档链接失效、文档声明与实测冲突、混合提案、重复提案、旧卡片兼容、并发配置变更，以及桌面/窄屏的当前与建议对照。
