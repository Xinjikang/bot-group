# 设计：成员发言规则与界面可读性改善（req#178）

- 需求：docs/requirements/2026-11-25-member-speech-ui-i18n.md（ID 178）
- 版本：2026-11-25
- 任务顺序：A（发言规则）→ B（中英切换）→ C（@ 点名）→ D（停止按钮）

## 1. 成员共用发言规则（任务 A）

落点：`engine/wake.py` 第 310 行起 `_COMMON_SYSTEM_PROMPT` 末尾，单列「成员发言」一段，现有编号不动。

原文逐字（用户 thread_id=10156; message_id=13352 给定）：

> 成员之间用简洁、自然的工作语言，直接说具体的事。不甩词，不说套话，不说黑话，不省略必要的文字，确保意思准确。用到专业词时，让旁观者从上下文就能读懂。

覆盖范围：`_WORK_SYSTEM_PROMPT`（356 行）与 `_CHAT_SYSTEM_PROMPT`（396 行）均由 `_COMMON_SYSTEM_PROMPT` 拼接，chat 与 work 两模式、全体成员均会读到。

约束：

- 该段为 byte-stable 常量（353 行注释），任何改动使整段提示缓存失效，文本必须一次定稿、不得反复修改；
- 改动生效需要引擎重启；按项目约定，生产引擎重启时点由用户决定，验收通过后通知用户手动重启。

## 2. 全界面中英文切换（任务 B）

现状：前端无语言机制，界面文字散落在 `frontend/index.html` 及各 js/css 文件。

方案：

- 新建集中词表，收录中英两种文字（简体中文 zh-CN 与 English，只支持这两种）；
- 设置面板加「语言 / Language」选项，标签中英双语呈现，使首次打开中文界面的英文用户也能找到；
- 选择后立即生效，持久化记住选择，下次打开沿用；
- 聊天页、设置页、管理页的界面文字（含按钮、提示、标记）统一从词表取。

边界：已发送消息保留原文，不做翻译。

验收：聊天页、设置页、管理页各抽一处中英对照；切换立即生效；重开记住选择；已发送消息原文一致。

## 3. @ 点名与「提到我」标记（任务 C）

- 消息正文中 @ 名字使用青色加粗文字，背景透明；
- 点到当前用户的消息旁显示对应语言标记（中文「提到我」、英文「Mentions you」）；
- 标记文字从任务 B 的词表取。

验收：新用户无提示扫一眼找到点到自己的消息；两种语言下标记文字正确。

## 4. 停止按钮可见性（任务 D）

思考气泡头部右侧的停止按钮使用红色图标和 12px 加粗文字，标签「停止 / Stop」随界面语言切换。点击区域至少为 40 × 26px。默认和悬停时背景均透明，悬停时描边变红。点击后打开确认框，确认后向当前成员和会话发送停止请求。

验收：新用户无提示找到并停掉一次正在生成的回复。

### 消息撤回按钮

消息行右侧的「撤回」使用 13px 文字、28px 最小高度和 10px 左右内边距。鼠标移入消息行时显示按钮，点击后打开该条消息的撤回确认框。

## 任务依赖

- 任务 B 前置 A：共享主目录串行开发约束，一次只允许一人修改代码（B 本身与 A 无成果依赖）；

## 总验收

找初次使用的人，不提示：读一段真实 bot 对话能说清发生了什么；找到点到自己的消息；停掉一次正在进行的回复；切换语言后聊天、设置、管理页文字全跟进。
