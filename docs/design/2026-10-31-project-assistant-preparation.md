# 项目助手的配置、资料准备与使用问答

## 目标与验收依据

统一需求及验收条款见[项目助手需求](../requirements/2026-10-31-project-assistant.md)。

项目助手承接不同项目类型的配置和资料差异。新建向导与项目详情使用同一套字段知识，结合模板职责、当前配置和已有资料协助用户填写。创建后检查模板要求的文件、文件内待填写内容和项目特有约定。测试项目收集产品需求及原型的权威来源，整理为模板规定的 `docs/product/PRD.md` 与 `docs/product/PROTOTYPE.md`，保留来源、版本和待澄清项。使用问答依据当前安装版本的文档和页面入口。

验收覆盖六类模板及空项目、已有文档与默认骨架的区别、部分读取和路径保护、原生 agent 实际文档产物、并发修改冲突、向导字段填写与详情配置修改、使用资料与项目资料的来源区分。实际文件、配置值和模型回答与无外部调用的契约测试分别记录。

## 实现

在各模板目录维护助手准备说明，声明输入、配置注意事项及当前阶段需要的资料。模板 manifest 的文件清单提供默认结构依据；准备说明只声明启动所需文档，阶段产物按流程后续完善。通用字段知识、模板说明及当前安装的使用文档组合进每轮上下文。文件检查提供路径、状态、待填位置和来源；截断、不可读与越界均保留未知状态。个性化结构和项目既有约定由模型结合实际资料判断。

执行机制采用[宿主原生工具设计](2026-10-31-project-assistant-native-tools.md)。文档由原生 agent 根据用户指令读取、编写并核验，HUD 展示实际结果摘要；配置通过project_config 业务工具复用现有校验和目录授权同步。原有文档提案保留历史兼容。

后台检查默认间隔一小时，创建会话已选择 AI 时在绑定成功回执后立即排队检查；尚未选择 AI 的草稿保留暂停状态，已有项目继续单独启用。绑定重试保持现有待办。模板默认文件中的说明和占位内容需要确认或补齐，文件存在本身只证明路径可用。使用知识从程序目录读取，与被管理项目中的声明分别标注。
