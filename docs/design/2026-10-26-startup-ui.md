# 启动入口与维护后界面刷新

## 行为与范围

Windows 安装完成后维护当前用户桌面的 Bot Group 快捷方式。快捷方式与 `start.bat` 共用 `tools/service.py start`：读取配置，核对服务身份，复用健康的同一实例；服务未启动时执行环境检查和启动，健康检查通过后打开默认浏览器。入口使用实际配置的端口，通配监听地址转换为本机回环访问地址。

快捷方式记录安装解释器、服务入口及数据目录，支持含中文和空格的路径。重复安装更新相同入口；已有同名链接属于其他实例时，追加程序根与数据目录的稳定标识以保持两者独立。桌面目录通过 Windows Shell 获取，支持桌面重定向。创建失败输出明确提示，服务安装就绪状态继续保留。无人值守安装可设置 `GROUP_DESKTOP_SHORTCUT=0`。

快捷方式使用安装目录的 `frontend/assets/bot-group.ico`，安装和升级同步更新图标引用。原图、各尺寸及视觉约束见 [桌面图标](../ui-spec/DESKTOP-ICON.md)。

快捷方式通过解释器设置当前进程的 `GROUP_DATA_DIR`，再运行服务入口的 `start` 命令。该入口同时兼容升级失败后恢复的旧版命令行参数。

手动启动复用当前客户端已连接的 UI 页面，并发送唤回请求；所有页面关闭后调用默认浏览器打开入口。快捷方式、`start.bat` 和 `start.sh` 共用此行为。`tools/service.py start --no-browser` 支持无人值守启动，`restart` 执行完整重启且保持浏览器状态。

## 页面复用协议

`frontend/ui_presence.js` 在页面加载时建立独立的 `/desktop/events` SSE 连接，登录页、后台标签页和业务连接断开时均保留页面登记；页面离开时关闭连接，恢复显示时重新连接。服务端按客户端地址归组，将 IPv4、IPv6 回环地址统一识别为本机。远端客户端的页面保持独立；多个本机页面优先选择最近建立连接的页面。

启动器在确认实例健康且程序根、数据库匹配后，以管理员身份请求 `POST /admin/ui/activate`。返回 `reuse` 时向已有连接发送激活事件，返回 `pending` 时合并正在打开的请求，返回 `open` 时调用默认浏览器。打开请求保留 10 秒，页面建立连接后清除；浏览器调用失败时，启动器通过 `DELETE /admin/ui/open/{reservation}` 释放匹配的占位，便于立即重试。占位过期后允许再次打开，覆盖浏览器未成功加载页面的情况。

SSE 仅传递激活信号，允许登录前登记，要求浏览器的 `Sec-Fetch-Site: same-origin` 元数据。打开和释放端点均要求管理员身份。页面尝试调用 `window.focus()`，实际切到前台的结果由浏览器策略决定。页面在线状态依赖当前 SSE 连接；刷新、网络中断和恢复期间存在短暂的重新登记窗口。纯 HTTP 的远端非可信源可能缺少 Fetch Metadata；本机回环地址支持此协议。

已运行旧服务返回 404 时，启动器提示手动重启并刷新页面，随后沿用打开浏览器行为。部署新代码后须手动重启服务，并刷新已经打开的旧页面，使路由与页面登记同时生效。其他状态核对错误会输出提示并结束本次打开操作。

## 维护流程

网页重启与升级助手传递 `GROUP_SERVICE_MAINTENANCE=1`，让启动入口执行原有的就绪检查、优雅退出、后台启动和健康检查。该环境标记在新引擎创建前移除；旧版本回滚入口沿用 `start` 命令并忽略未知环境变量，保持恢复兼容性。

旧版重启助手沿用 `GROUP_RESTART_INSTANCE` 识别维护启动。旧版升级助手由运行中的升级回执识别，要求回执的助手 PID 等于启动器的直接父进程，且程序根、数据库均与本次安装相符；同时手动启动的独立进程保持手动入口语义。

页面在操作回执成功、健康状态正常、新实例标识及程序根和数据库一致后清除本次监控记录，自动刷新当前整页以加载静态资源。刷新前保持维护状态，抑制额外 SSE 重连与局部数据请求；新页面按常规初始化恢复连接。失败、超时或实例核验未通过时保留结果/等待状态。已有会话令牌和项目选择沿用现有存储恢复机制。

## 验证

- 服务单元用例覆盖启动后打开、已运行复用、失败阻断、浏览器不可用、实例目录核对及命令行数据目录传播。
- Windows 隔离程序、数据库和随机端口验证 BAT 冷启动、再次启动保持实例 ID、浏览器请求地址，以及网页重启仍更换实例且保持浏览器调用次数。
- Windows Shell 在临时桌面创建、读取和重复维护真实 `.lnk`，执行惰性替身入口核对中文、空格和特殊字符路径及数据目录参数。
- Chrome 拦截 HTTP 验证重启/升级中手动刷新恢复监控、新实例门槛、成功后自动刷新一次、刷新后清除监控记录与失败保留页面。
- 真实 Chrome 连接隔离服务器，执行实际 BAT 与临时桌面 `.lnk`，验证首次打开、快速重复、登录页、后台页、刷新、多页面和全部关闭后重新打开；浏览器打开调用由记录器接收，核对引擎实例和 PID 保持一致。
