# Profile 模型凭证继承与执行异常反馈

创建 Bot 默认完成模型配置准备，减少重复填写来源已配置的凭证。默认来源映射至 Hermes 主 profile；显式来源映射至所选目录。复制范围为内置 provider 元数据及来源自定义 provider 明确声明的模型凭证和地址。模型定义与凭证同时迁移，消息渠道和其他工具环境变量保持独立。

Hermes 版本间的内部方法与数据格式可能变化。引擎使用独立 AST/JSON/YAML 数据适配器读取 provider 定义，避免导入或执行 Hermes 模块。扫描结构不匹配时明确失败并回滚；新增宿主版本通过兼容性测试后更新适配器。浏览器配置、动态凭证命令及运行时插件元数据属于后续兼容范围。

Bot 可能在模型和 MCP 初始化之前退出。异常可见性由引擎负责：统一分类文案、原会话定位、持久化及按执行去重；诊断内容脱敏保存。通知绕过 Bot 消息路由，防止失败通知再唤醒 Bot；主动停止沿用已有交互。

实现与验证契约见 [创建 profile](../engineering/PROFILE-CREATE.md)、[执行异常](../engineering/EXECUTION-ERRORS.md) 和 [测试索引](../../scripts/TEST_INDEX.md)。
