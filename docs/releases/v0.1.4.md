# v0.1.4 — 2026-10-25

本版本精简 Bot 提示词，完善 Hermes profile 凭证继承、执行异常反馈与后台重启诊断。

## 更新内容

- 清理唤醒提示词、MCP 工具说明和错误提示中的重复规则来源声明，保留具体操作和参数要求。同步调整 22 份角色参考、算法及测试模板的启动阅读要求，六类模板递增补丁版本。
- 创建 Hermes profile 时，按所选模型渠道继承来源 profile 的适用凭证及服务地址。执行失败显示分类后的错误，持久保存并去重；错误信息脱敏，主动停止保持原有语义。
- 后台重启保留安装检查的标准输出与错误输出；检查失败时保留旧实例，诊断写入重启日志。
- 增加真实模型规则加载探针，使用隔离数据库、项目与 Hermes home，记录三次连续唤醒的工具调用、回复和收件箱状态。

## 安装与升级

新安装使用 [README](../../README.zh-CN.md#安装与启动) 的公开安装命令。发布资产为 `bot-group-v0.1.4.zip`、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。

Release 安装通过“设置 → 关于”检查并升级，完成后刷新页面。Git 工作区更新后执行 `tools/install.py repair` 同步依赖与就绪记录，再手动重启引擎。MCP 由宿主重新加载，Hermes 网关持有的进程通过网关重启更新。

模板修改作用于后续生成与引用；已有项目文件和 Bot 人格配置由维护者按需更新。会话中已保留的历史内容仍按宿主的会话机制管理。

提示词、任务流转和六类模板的 41 项回归通过，安装、发布资产、旧版升级及 BAT 的 34 项回归通过，凭证、执行错误与后台重启的 19 项回归通过。本机 Hermes `deepseek-v4-pro:0813` 在隔离项目连续三次真实唤醒中，均正确回答已注入的规则令牌、角色和业务结果，目标规则文件读取调用为零，入站消息均已读；原有宿主配置指纹保持一致。该结果覆盖本机所测模型与场景。
