# v0.2.4 — 2026-11-02

本版本加入 DeepSeek Harness（DSH）宿主支持，统一 profile 创建与模型配置，改进项目助手和 Hermes 网关会话复用。

## DSH 宿主

- 支持发现和绑定 DSH HOME、创建独立命名 profile、后台执行、会话续跑、思考记录及停止操作。刷新成员列表和读取思考记录使用 DSH 自身会话路由。
- 创建时由用户填写 profile 标识，优先从 desktop 带入模型与供应商；两项成对填写并保存。认证使用所选供应商对应的原生凭据，同一 HOME 可共享账号与 API key 配置。
- 成员编辑保留“描述、人格、模型与供应商”。人格保存到 profile 的 personaPrefix；模型、供应商及推理强度支持项目覆盖和全局保存。移除指令、环境和 Auto 编辑入口及对应成员接口字段。
- 启动时检测 Auto 审批插件，检测到就强制启用；未检测到则沿用原生审批。Auto 设置开关移除，旧 profile 开关退出控制逻辑。运行中继续校验审批预设并记录审查及工具执行结果。

## Profile 与项目助手

- Hermes 与 DSH 创建表单同时显示必填模型和供应商，来源配置自动带入；手动编辑后保留输入，切换宿主分别恢复草稿。Codex 保留可选模型输入。
- 项目助手通过原生 Bot 工具准备文档、操作项目配置和打开相应页面，沿用所选 profile 的会话与记忆机制。
- 完善角色文本校验、配置同步、已解决待办收尾与项目隔离。

## 执行稳定性

- Hermes 网关按会话复用执行资源，改进连续执行、项目助手会话复用及终态清理恢复。
- 修复授权签名轮换竞争，隔离大量历史数据读取，明确引擎连接与网关连接状态。

## 验证与升级

DSH 成员设置与既有宿主回归通过 108 项单元测试、DSH 及 Hermes/Codex 成员编辑浏览器用例。原生 DSH 配置探针确认 Auto 强制启用与适配插件组合，探针模型请求数为零。源码资产清单、公开安装入口与隔离安装按发布流程验证。

Release 安装通过“设置 → 关于 → 检查新版本”或 `upgrade.bat` 升级。Git 源码安装更新后手动重启引擎并刷新页面；旧页面需刷新后使用新的 DSH 成员接口。DSH profile 的 `.env`、AGENTS.md 和原生凭据文件由宿主继续管理。

发布资产包含源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。操作步骤见 [发布指南](../guides/RELEASE-GUIDE.md)。
