# v0.2.6 — 2026-11-03

本版本修复 Hermes 换证失败时阻挡其他独立会话调度的问题，补齐失败诊断，并统一助手扫描的根目录解析。

## 修复

- 原生会话空闲但换证配置失败时，短期暂缓该会话，允许其他独立会话继续调度。原唤醒记录的 ID、队列顺序和旧凭据保持；错误解除后沿用原会话完成换证及投递。
- 维护与换证派发日志增加操作阶段、项目、成员、会话、宿主目录、签名代、异常类型、HTTP 状态及脱敏原因，便于定位连接、恢复会话和配置阶段的故障。
- 从个人 profile 环境启动时，助手扫描正确还原 Hermes 根目录并发现同级助手。宿主发现、旧成员登记和配置编辑共用解析规则；已登记成员继续使用保存的宿主目录连接。

## 验证与边界

换证调度和诊断通过 102 项隔离回归，覆盖失败时其他独立会话可调度、原记录保持、故障解除后恢复及日志脱敏。根目录解析通过 67 项隔离回归，覆盖继承 profile 环境、平台默认目录、助手扫描、配置编辑与已登记成员连接。

换证等待继续保留旧代引用；故障会话恢复依赖实际连接、配置或授权错误解除。[Issue #19](https://github.com/Xinjikang/bot-group/issues/19) 的现场持续换证失败原因仍待日志核实。调度规则见 [Hermes 网关执行适配](../engineering/HERMES-GATEWAY.md)。

## 升级

Release 安装通过“设置 → 关于 → 检查新版本”或 `upgrade.bat` 升级。Git 源码安装更新后手动重启引擎并刷新页面。

发布资产包含源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。操作步骤见 [发布指南](../guides/RELEASE-GUIDE.md)。
