# v0.2.2 — 2026-10-29

本版本修复项目助手的提案超时续接和工作区资源读取，并增加 Hermes 网关执行的网页授权入口。

## 项目助手

- 待处理提案持续阻止空闲超时重置；追问、普通解释和逐条讨论保留原提案，每轮向模型提供完整内容。
- 确认提案或点击“暂不处理”后重新计算空闲时间；无待处理提案时继续沿用已设置的超时重置机制。
- 从已保存的工作区资源配置读取端口、浏览器和测试数据目录，按实际目录识别成员共享关系，修复已配置资源被误报为零项的问题。
- 区分资源尚未保存与目录归属待核实；处理补充期间以及提案标识过期时，确认操作返回明确提示。

## Hermes 网页授权

- 在对应项目和话题中显示 Hermes 网关提供的命令与编辑授权请求，展示执行内容、原因和可选范围。
- 本会话允许和长期允许均需二次确认；提交前重新核对原生请求和执行轮次，避免处理过期请求。
- 仅管理员可以查看和处理授权。执行结束、快照过期和连接异常时禁用操作；刷新页面后恢复仍在等待的请求。
- 提交结果未知时保留核对状态，通过后续查询确认结果。

## 验证与升级

助手回归覆盖超时追问、八项提案完整传递、历史窗口截断、提案确认与撤下，以及共享和独立工作区的资源读取；隔离 Chrome 验证追问、刷新和桌面/窄屏操作。授权与发布回归覆盖权限、执行归属、过期状态、原生回执和源码资产边界。

本次助手浏览器验证使用固定响应，模型自主检索历史和工具能力继续沿用现有边界。当前会话中已被旧版本撤下的提案保留在历史记录中，升级过程保持该历史数据。

Release 安装可通过“设置 → 关于 → 检查新版本”升级；Windows 也可运行 `upgrade.bat`，macOS/Linux 使用 `./upgrade.sh`。升级后重启引擎并刷新页面。Git 源码安装更新后手动重启引擎。

发布资产包含源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。安装与恢复步骤见[发布指南](../guides/RELEASE-GUIDE.md)。
