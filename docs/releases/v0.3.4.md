# v0.3.4 — 远程 Hermes 长历史与会话恢复

远程 Hermes 恢复已有会话时会返回聊天记录。旧插件接收超过 1 MiB 的回复时会以 WebSocket 关闭码 1009 断流，引擎可能继续等待 30 秒，导致消息在提交前超时。

两个连接方向现均按块转发网关回复，按原顺序组装后交给原 RPC 调用方。单次完整回复支持至 64 MiB。内层网关断开时，引擎及时收到断流通知。关闭读取后，插件释放对应的网关连接。

远程思考记录改为后台读取。浏览器限制并发，同一远程会话共享读取，失败后延迟重试。慢节点上的历史查询期间仍可打开节点管理并使用其他页面操作。

**升级**　办公机引擎和云端插件请一起升级到 v0.3.4，并重启引擎及对应 Hermes 网关。具体安装步骤见 [远程插件指南](../guides/BOT-GROUP-RELAY-INSTALL.md)。

**验证**　在真实 ECS 上，原会话的完整回复为 1,063,985 字节，含 177 条消息。办公机页面经 relay 读取单轮和完整时间范围，分别展示 5 条和 89 条记录，两组内容、顺序和游标均与 ECS 直读结果一致。两个拨号方向另以超过 8 MiB 的合成历史验证恢复、导出和断流处理。
