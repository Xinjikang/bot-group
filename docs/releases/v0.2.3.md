# v0.2.3 — 2026-10-30

本版本调整项目助手的对话和待办界面，修复待办误报与跨项目展示，并改进 Hermes 网关执行和话题成员管理。

## 项目助手

- 消息区固定提供“对话消息”和“待办事项”两个标签，待办统一采用卡片，按当前项目或创建草稿隔离。
- 待办卡片保留独立回答、确认和暂不处理操作，数量不限；切换标签保留未发送输入，对话显示本轮用户消息与最新助手回复。
- 移除更多菜单中的跨项目待处理列表、其他项目计数和跳转；轮询只读取当前助手会话。
- 成员修改代码、提交和更新索引等进度保留在对话。普通待办标记以实际问题或提案卡片为依据，兼容旧 pending 数据；明确需要用户介入的行动才自动展开，手动收起状态可跨页面刷新保留。

## Hermes 执行与设置

- 复用同一宿主的网关连接，增加空闲回收、断线恢复和顶栏连接状态。
- `/steer` 接入网关运行轮次纠偏，保存投递回执与消费证据，区分未送达和结果待核对状态。
- 持久记录系统和用户规则的提交状态，减少连续唤醒时重复注入，并补齐旧会话与回执不确定时的处理。
- 设置中增加全局 Hermes 文件编辑审批策略选择，按后续执行应用；共享工具支持 `operation_get` 查询。

## 话题成员

- 话题成员候选按所属项目的有效入组成员加载，停用成员保留明确状态，已有话题参与者可移出。
- 成员列表覆盖空状态、读取失败重试、项目切换和异步响应归属。

## 验证与升级

回归覆盖助手标签与卡片、旧提醒误报、项目隔离、网关连接和纠偏、规则判重、编辑策略、成员范围，以及源码安装和旧版升级兼容。助手浏览器验证使用固定响应与隔离数据，覆盖桌面和 390px 深浅主题。模型自主判断的语义仍需结合实际事项核对。

Release 安装可通过“设置 → 关于 → 检查新版本”升级；Windows 也可运行 `upgrade.bat`，macOS/Linux 使用 `./upgrade.sh`。升级后重启引擎并刷新页面；Git 源码安装更新后手动重启引擎。

发布资产包含源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。安装与恢复步骤见[发布指南](../guides/RELEASE-GUIDE.md)。
