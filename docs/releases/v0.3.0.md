# v0.3.0 — 2026-11-22

- **远程 Hermes 入组。** 支持云端主动连接办公机，以及办公机主动连接云端。管理员确认配对后，网关用已保存的凭据恢复连接。同名本地和远程成员可同时入组，远程成员名称带括号标识。换发凭据时，页面提供可复制的命令。
- **远程安装与协作。** Linux 单文件安装器随引擎一起发布。每个远程节点可设置协作根目录；引擎根据项目模式准备共享仓库或成员 worktree。成员可以先聊天，再同步代码基线并领取任务。[配置与一行安装](../../README.zh-CN.md#接入远程-hermes)
- **会话与任务恢复。** Hermes 会话按模型切换回执更新状态。任务停滞时，引擎核对任务、会话与执行回执，支持在原会话续办；未接手的恢复唤醒可由用户解除。
- **消息交互。** 话题消息先确认发送，再由后台安排成员发言。主输入框随内容调整高度并保持光标可见。

Windows 安装和升级继续使用原有入口。Git 源码部署请更新到此标签，再手动重启引擎。远程节点使用本标签的插件安装器，安装后重启对应 Hermes gateway。[安装与升级指南](../guides/RELEASE-GUIDE.md)
