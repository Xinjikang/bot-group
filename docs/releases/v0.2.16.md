# v0.2.16 — 2026-11-18

- **Hermes 网关恢复。** 网关升级或断线期间，如果 bot-group 记录执行状态时遇到 SQLite 写锁，回执核对线程会退避重试。恢复连接后继续查询原执行，已完成的回合可以正常收尾。Hermes 仍返回 `unknown` 的回合保留待核实状态。[网关执行与恢复](../engineering/HERMES-GATEWAY.md)
- **Windows 服务重启。** 旧引擎退出时，状态查询可能收到 Windows 错误 10053（连接中止）。重启脚本会继续核对旧进程和端口，确认两者都已释放后启动新实例。[部署与重启](../guides/DEPLOY.md)
- **发送卡顿诊断。** 仓库中的维护探针分别检查数据库连接、消息路由和发送总耗时。默认阈值依次为 5000、3000、5000 毫秒。任一项达到阈值即记录该请求及全部触发项。采集结果区分零样本、样本均低于阈值和捕获异常三种情况。探针随 Git 源码提供。[探针设计](../design/2026-11-17-probe-detection-patch.md)

Release 安装可在“设置 → 关于 → 检查新版本”升级。Git 源码安装更新后，手动重启 bot-group 引擎并刷新页面。[安装与升级指南](../guides/RELEASE-GUIDE.md)
