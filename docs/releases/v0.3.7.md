# v0.3.7 — 远程 Hermes 私聊重连

- 云端 Hermes 主动连接引擎时，自动重试停止后，在原来的 Hermes 私聊里说「重连」即可。插件使用已保存的地址和凭据重新拨号，私聊说「查看 relay 状态」可确认是否在线。
- 查询状态、注册、开启监听和重新拨号四个工具统一使用 Hermes 网关的私聊准入规则。升级后无需配置 `BOT_GROUP_RELAY_ADMIN`。首次配对及引擎侧凭据校验沿用原有流程。
- 项目向导初始化的 Git 仓库会设置仓库级非交互编辑器，自动化 Git 操作可直接使用已准备的提交说明。

在远程 Hermes 所在机器，用本版 `install-relay.pyz` 更新已配对的 profile，再重启该 profile 的 Hermes 网关。具名 profile 使用 `python3 install-relay.pyz --profile <名称>`。详见[远程插件安装指南](../guides/BOT-GROUP-RELAY-INSTALL.md)。
