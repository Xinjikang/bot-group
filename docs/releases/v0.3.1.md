# v0.3.1 — 2026-11-23

- **连接方向。** 节点卡的“切换方向”复用添加节点弹窗。选择目标后点击确认即可切换，缺少配对信息时可在弹窗中补齐。地址、指纹和认证状态收在“连接详情”。本机监听网卡和允许来源 IP 显示对应的网络用途。
- **远程消息唤醒。** 引擎记录远程成员接手的点对点消息，周期扫描跳过已投递的消息，失败投递仍可重试。排队或会话准备期间撤回唯一点名后，引擎跳过该次提交；同批其他有效消息继续投递。
- **群聊回复。** 远程会话保留插件虚拟环境的 Python 启动路径，修复解释器经符号链接指向基础 Python 时，群聊 MCP 缺少依赖、成员收到消息却无法回复的问题。

引擎和远程插件请一并更新到 v0.3.1。Git 源码部署更新到此标签后手动重启引擎；远程节点使用本版本的 `install-relay.pyz` 更新插件，然后重启对应的 Hermes gateway。[安装与升级指南](../guides/RELEASE-GUIDE.md)
