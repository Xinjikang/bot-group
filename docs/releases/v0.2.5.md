# v0.2.5 — 2026-11-03

本版本改进 Hermes 子代理等待和跨会话调度，修复停止恢复与大历史预检查，并调整新项目助手选择及主题显示。

## 执行与调度

- 父 agent 等待后台子代理时保留任务归属和话题发言位；原生回调续接同一逻辑执行，继续校验消息和任务写入权限。
- 等待中的工作会话可以连续接收点对点消息；不同话题、不同 Bot 的工作会话继续独立调度。
- `/thinking` 恢复本地快照读取，消除 HTTP 状态读取中的网关查询。
- 用户停止时补齐父回调 admission 为 `unknown` 的恢复路径，支持取消确认超时后的手动重试及响应丢失后的终态核对。
- 忙闲预检查省略完整消息历史，避免大历史超过共享控制连接的接收上限。
- 改进取消状态同步、重启后停止恢复及旧成员 Hermes 宿主定位。

## 界面与项目配置

- 新项目单独选择助手，已有项目及已保存草稿保留各自配置；移除“下次预选”全局设置。
- 修复新建话题标题自动填充后的深浅主题颜色，保留输入框布局和边框。
- 设置中增加引擎日志查看入口，调整 profile 可选默认值及模板控件布局。
- 六类项目模板补充管理支持职责和重复返修后的讨论规则。

## 行为边界与验证

正常委派等待跨过普通执行超时后继续保留任务和发言位，异常处置依据明确失效事实或用户停止。父轮结束后停止思考显示；原生回调复用同一执行标识时，实时思考内容刷新仍存在限制。具体契约见 [子代理等待设计](../design/2026-11-03-delegation-wait.md)。

停止恢复、大历史连接、等待归属、跨会话调度、本地思考查询和话题重启恢复通过 155 项隔离回归。默认 ACP 工具集下的原生父子代理、点对点输入、MCP 消息及任务交接已有隔离验收；本次停止修复采用合成 RPC 验证，原生网关重启导致父回调 unknown 的完整触发链仍待专门验证。话题颜色与新项目助手选择沿用各自通过的浏览器回归证据。

## 升级

Release 安装通过“设置 → 关于 → 检查新版本”或 `upgrade.bat` 升级。Git 源码安装更新后手动重启引擎并刷新页面；已有 `manual` 执行需要再次点击停止触发核对。Hermes 源码保持独立，项目数据和宿主配置沿用原值。

发布资产包含源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。操作步骤见 [发布指南](../guides/RELEASE-GUIDE.md)。
