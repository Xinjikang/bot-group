# v0.1.6 — 2026-10-27

本版本修复需求超时拆解的重复空唤醒，并统一设置菜单图标与资源配置界面。

## 更新内容

- 修复 [Issue #4](https://github.com/Xinjikang/bot-group/issues/4)：扫描与唤醒共用需求恢复条件，阻塞子任务暂停自动恢复；部分拆解保留已有任务上下文，支持继续补齐并完成拆解。
- 需求扫描队列在投递前重新核对需求、未读消息和可执行任务，过期空队列自动取消；合并的消息与任务继续处理。缺少可拆解成员时，向有效负责人提供配置协调指令。
- 设置菜单五项入口采用统一的 16px SVG 线性图标；主题切换与服务重启进度更新时保持图标、文字与间距一致，兼容深浅主题和窄屏。
- 调整工作区资源控件和操作按钮间距；角色权限减少时提示影响，新增授权按选择直接更新。

## 安装与升级

新安装使用 [README](../../README.zh-CN.md#安装与启动) 的公开安装命令。发布资产为 `bot-group-v0.1.6.zip`、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。

Release 安装通过“设置 → 关于”检查并升级，或运行 `upgrade.bat`。Git 工作区通过 Git 更新，执行 `tools/install.py repair` 同步就绪记录后手动重启引擎，并刷新页面加载图标资源。本版本无需新增数据库迁移。

## 验证范围

需求恢复回归覆盖连续扫描、阻塞与恢复、部分拆解、权限与来源变化、负责人协调、消息/任务合并及领取竞态。设置菜单与重启浏览器回归覆盖动态状态、深浅主题及 390px 窄屏。

发布构建核对 Git 文件、源码清单、VERSION 与资产摘要。公开安装验收使用独立端口及数据目录，验证匿名下载、真实依赖安装、重复安装、BAT 启停、HTTP 页面与默认升级检查。方法见 [测试索引](../../scripts/TEST_INDEX.md)，证据保存到项目主目录 `reports/tests/v0.1.6/2026-10-27-release/`。
