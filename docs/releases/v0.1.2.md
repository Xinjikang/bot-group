# v0.1.2 — 2026-10-23

本版本增加网页升级、统一成员选择，并修复背景弹窗、源码版本识别和旧安装升级兼容。

## 更新内容

- “设置 → 关于”支持检查新版本；有更新时提供升级按钮，右上角版本提示直接打开升级确认框。确认后自动校验、备份、升级并启动服务，失败时恢复旧版。支持进度回执、页面刷新续查及升级与重启互斥。
- Release 安装读取包内版本号；Git 源码显示正式 tag、提交号、提交距离和本地修改状态。首次打开、每 12 小时及休眠恢复后检查更新，支持手动重查。
- “选择成员”与项目向导共用候选列表，只展示尚未加入当前项目的 Bot；刷新保留选择，部分加入成功后移除成功成员。独立创建 Codex/Hermes profile，支持来源配置、SOUL 参考、取消后保留和创建失败重试。
- 右上角设置菜单集中管理称呼、背景、主题、重启与关于；换背景弹窗稳定定位在右侧设置按钮下方。
- 成员启停使用明确的“启用 / 停用”控件；角色删除、改名和权限调整显示职责与授权影响提示。
- 完善收件箱确认规则：读取和发送回复后继续核对确认结果；六类项目模板明确执行请求、已有任务续做与任务分工的处理约定。
- 安装、发布、升级和服务维护工具统一移至 `tools/`；仓库 `scripts/` 保留测试。发布包生成受清单管理的旧路径转发入口，兼容 v0.1.0/v0.1.1 原升级器。

## 安装与升级

新安装使用 [README](../../README.zh-CN.md#安装与启动) 的 PowerShell 或 CMD 命令。发布资产包括 `bot-group-v0.1.2.zip`、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。

v0.1.0/v0.1.1 安装在原目录运行 `upgrade.bat`，成功后运行 `start.bat` 并刷新浏览器。手动配置数据目录的安装使用原有 `GROUP_DATA_DIR`。进入 v0.1.2 后，后续版本可从网页“关于”发起升级。

网页自动升级适用于具有有效版本号和文件清单的 Release 安装；Git 工作区通过 Git 更新。MCP 工具说明更新后重新加载宿主；Hermes 网关持有的 MCP 进程随网关重启加载。

## 验证范围

版本识别与安装升级回归覆盖真实 Git、文件级清单、旧升级器兼容、数据库和附件保留。Web 升级在隔离 Windows 实例验证 API、独立助手、下载校验、备份迁移、服务恢复，以及就绪失败和新服务启动失败后的旧版恢复。Chrome 验证两个升级确认入口、响应丢失、刷新续查、成员选择与创建、背景定位及窄屏深浅主题。

发布资产校验和公开安装验收记录保存在项目主目录 `reports/tests/v0.1.2/2026-10-23-release/`，执行产物随项目备份保存。
