# v0.2.9 — 2026-11-04

本版本修复 DSH 成员执行恢复和命名 profile 加载，并为项目助手接入 DSH。

## 修复与新增

- 修复缺失 PID 的残留执行记录持续占用成员：通过原生进程参数核验会话身份，确认退出后恢复调度，查询失败时保留并发保护。启动后立即登记 PID，DSH 长提示词通过后台线程提交，stdout/stderr 同时排空。
- 命名 CLI profile 按所选名称启动，原生加载自身 bundle 和配置；执行 overlay 保留认证控制及项目模型覆盖，避免重复添加 profile 中的插件。desktop 继续使用已有 headless 后台适配。
- 项目助手支持 DSH：继承所选 profile 的模型和人格，提供原生文件工具及私有配置、页面导航 MCP，保留 Auto 审批、工具范围控制、协议校验和进程树清理。

关联问题：[成员 busy 恢复 #22](https://github.com/Xinjikang/bot-group/issues/22)、[DSH 项目助手 #23](https://github.com/Xinjikang/bot-group/issues/23)、[Profile 加载 #24](https://github.com/Xinjikang/bot-group/issues/24)。实现边界见 [设计说明](../design/2026-11-04-dsh-execution-recovery-hud.md)。

## 验证与范围

隔离回归覆盖 DSH 配置、执行生命周期、进程查询、话题重启、停机和 HUD；最终定向 11 项全部通过。实际 DSH CLI 验证使用临时 HOME、合成模型流和独立 MCP，确认人格、受限工具清单、Auto preset、文件读取和项目配置工具调用；外部模型调用为零。

已知问题：HUD 空显示名校验有一条既有用例失败，已在修复前的独立源码快照中复现；本版本保持该校验行为。

## 升级

Release 安装通过“设置 → 关于 → 检查新版本”或 `upgrade.bat` 更新。Git 源码安装更新后手动重启引擎并刷新页面。旧版在公共 headless 目录创建的会话如在独立 profile 下提示缺失，使用 `/new` 开始新会话，历史记录保留。

发布资产包含源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。安装和升级步骤见 [发布指南](../guides/RELEASE-GUIDE.md)。
