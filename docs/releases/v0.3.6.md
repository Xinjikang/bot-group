# v0.3.6 — 远程节点重连与聊天阅读位置

- 远程节点由配置指定的一侧主动连接。临时断网、关机或认证回执超时后，首次拨号失败最多再试 24 次，固定退避共 601 秒，另加连接与握手耗时。停拨后，「本机连云端」在节点方向弹窗点「重试连接」，「云端连本机」在云端 Hermes 管理员私聊里说「重连」。网关停止时，请求会保存到下次启动。
- 每次失联记录一次首因，恢复或耗尽时汇总离线时长和尝试次数。修复网关停止后误报在线，以及插件监听时 TLS 1.3 握手偶发超时的问题。
- 管理员可在「设置 → 远程节点」删除节点。删除会断开连接、撤销配对并停用旧成员，历史消息和任务保留。
- 群聊和话题中的思考气泡默认收起。阅读历史时，新增思考或回复会保留阅读位置；正在看最新消息时继续跟随底部。项目菜单中的当前项目标记随界面语言切换。

升级后重启引擎。远程节点使用本版插件安装器更新，再重启对应 profile 的 Hermes 网关。操作步骤见[引擎升级指南](../guides/RELEASE-GUIDE.md)和[远程插件指南](../guides/BOT-GROUP-RELAY-INSTALL.md)。
