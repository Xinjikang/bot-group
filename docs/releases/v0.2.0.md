# v0.2.0 — 2026-10-29

本版本修复项目助手的 Hermes 对话连接，增加实时推理进度，并完善创建向导与助手的联动体验。

## 项目助手对话

- 新版 Hermes 的项目助手复用群聊已有的网关连接与公开会话接口，沿用所选 Bot 的模型配置。旧版 Hermes 保留公开 CLI 调用路径，Codex 沿用独立执行方式。
- 维护对话使用独立会话，提交前核验工具清单为空；项目资料与提案通过既有维护流程处理，配置提案经用户确认后生效。
- 保存执行与回执标识，断线后的显式重试先核对原执行；提交结果未知时保留待核对状态。超时按实际执行状态取消或中断，并核对终态。
- 检查期间显示最新推理摘要或处理阶段及耗时，刷新后恢复进度；结束或失败后停止计时。推理内容的提供情况取决于模型和宿主。
- 普通文本回复按对话显示，结构化配置提案继续进行格式与权限校验，并等待用户确认。

## 界面与使用流程

- 项目创建和导入向导与助手并排展示，右侧空间充足时保持顶部对齐、等高和独立滚动；窄窗口采用浮层，保留表单草稿。
- 设置页将 AI 选择和空闲时间分组，统一取消与保存操作。
- 更多菜单保留已确认资料与设置，助手随当前项目详情或创建向导切换上下文。
- 中英文 README 新增推荐协作流程，覆盖需求讨论、方案审核、任务执行、持续输入需求和阶段审查。

## 支持范围与升级

Hermes 网关基线为 v0.22.5（`bf0203a7`）；该版本已验证原生编辑策略、会话导出迁移、MCP 更新、引擎回复与已读、取消收尾和新会话切换。旧版 CLI 的既有验证基线为 v0.21.1 和 v0.21.3。其他构建按实际接口和协议能力核验。

Release 安装可通过“设置 → 关于 → 检查新版本”执行网页升级，或运行 `upgrade.bat` 后使用快捷方式或 `start.bat` 启动。Git 源码安装更新后运行 `tools/install.py repair` 并重启引擎。Hermes 安装更新后需重启对应网关，使运行代码与安装版本一致。

项目助手需在设置中选择 Bot，并对相应项目启用维护。对话、权限边界和提案行为见[项目助手工程契约](../engineering/PROJECT-HUD.md)，安装与升级见[发布指南](../guides/RELEASE-GUIDE.md)。

本次发布提供源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1` 六项资产。
