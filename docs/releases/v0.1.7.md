# v0.1.7 — 2026-10-28

本版本支持 Hermes 0.22.5 官方网关执行，修复群聊工具注入、成员保留名称校验，并支持托管执行跨引擎重启继续运行。

## Hermes 支持范围

| 版本 | 执行方式与验证范围 |
| --- | --- |
| 0.22.5（`bf0203a794a07aac3ff764972ab9087baa4e4f4e`） | 官方网关路径；真实模型、群聊 MCP、取消、会话迁移、配置刷新和连续两次引擎重启已验证。 |
| 0.21.1（`cdf4c765`）、0.21.3（`afc3b7c6f3`） | 保留本地 CLI 路径；已验证旧版会话创建、恢复、历史和兼容接口。 |
| 其他版本或开发构建 | 按实际源码布局、会话接口和网关协议能力检查；逐版本完整验证仍需另行完成。 |

本次网关版实测基线到 **Hermes 0.22.5**。小于 0.22 的旧版继续通过本地 CLI 子进程执行，每次执行使用临时 MCP 配置和专属凭据。旧版缺少 `hermes_state_ids` 模块时，使用其原有的时间戳加六位 UUID 会话 ID 格式；会话数据仍由 Hermes 原生 SessionDB 管理。引擎识别网关源码布局后，改走官方 CLI、control ticket、`hermes-gateway-v1` 及会话级 MCP，并校验所需协议能力。版本字符串用于诊断，实际能力决定可用路径。

引擎重启接管适用于网关托管执行；旧版 CLI 与 Codex 沿用本地执行的停机收尾流程。Hermes 网关自身升级或重启应安排在当前执行结束后。

## 更新内容

- 修复 [#9](https://github.com/Xinjikang/bot-group/issues/9)：网关获得每轮 task_queue MCP、执行凭据与项目上下文，成员可以读取收件箱、回复群聊和流转任务。
- 修复 [#8](https://github.com/Xinjikang/bot-group/issues/8)：创建、注册、发现和入组统一检查 Hermes 保留名称，运行失败显示明确的配置原因。历史成员的重命名及数据迁移需独立处理。
- 引擎重启关闭本地连接，保留网关中的原执行；启动后按原 admission 接管，避免重复派发。执行凭据及旧 MCP 进程可跨连续重启延续，终态凭据及时撤销。
- 分离执行终态与异步清理；取消、清理及 MCP 离线重试使用有界预算，未知请求通过持久回执对账。已有 admission 的长任务断线沿用原执行截止时间。
- 工具描述在下次空闲唤醒刷新；AGENTS、SOUL 和记忆通过 `/new` 刷新。界面显示实际停止或查询结果，保留停止按钮。
- 修复启动脚本、CODEX_HOME 探测及默认数据库目录迁移，保留自定义数据布局；完善运行异常分类。

## 安装与升级

新安装使用 [README](../../README.zh-CN.md#安装与启动) 的公开安装命令。Release 安装通过“设置 → 关于”或 `upgrade.bat` 更新。Git 工作区更新后执行 `tools/install.py repair` 同步依赖并手动重启引擎。

本版本包含数据库迁移和持久签名密钥。升级流程先备份再迁移；首次升级遇到在途 Hermes 执行且缺少可迁移密钥时，会提示等待执行结束。请保留实例数据目录及 `secrets/bot-signing.key`，备份应同时覆盖数据库和匹配密钥。

更新引擎后重新加载 MCP 宿主；Hermes 网关持有的旧 MCP 需通过重启对应网关加载新版。升级 Hermes 时先等待当前任务结束，再重启网关和引擎。现有生产实例由管理员执行升级和重启。

## 验证与边界

独立复审通过 208 项回归；架构验收独立复跑核心 84 项（范围重叠）。真实 Hermes 0.22.5 与同一成员两个话题的验证 7/7 通过：UI 和脚本连续重启后，原执行与 MCP 进程保持、各回复一次、终态凭据返回 401，清理完成且隔离资源释放。浏览器覆盖重启确认、进度、刷新恢复及失败提示。

无 task_id 的聊天执行没有硬截止时间，网关永久不可达时可能长期保留占用；提交回执丢失且尚无 admission 时保留未知状态，避免重复执行。Hermes 网关自身重启恢复及 POSIX 权限实跑保留为范围边界。

发布资产为源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。构建核对源码清单及摘要；验证方法见 [测试索引](../../scripts/TEST_INDEX.md)，发布证据归档至项目主目录 `reports/tests/v0.1.7/2026-10-28-release/`。
