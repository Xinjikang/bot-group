# v0.3.8 — 项目向导、成员管理与 Hermes 更新

- 项目初始化向导支持重新检查首次提交范围、逐个展开文件差异，并按勾选结果创建提交。
- 话题卡片的“成员管理”可以正常打开，已收口的话题也能查看和调整成员。SOUL 模板弹窗的关闭按钮随界面语言显示“关闭”或“Close”。
- 创建 Hermes profile 时支持新版和旧版凭证定义格式，使用 Ollama Cloud 等供应商的成员可以继承来源 profile 的模型凭证。
- Hermes 后台进程等待及任务恢复待审期间会释放工作队列，运行中的纠偏消息按用户消息传递。远程 Hermes 支持通过 relay 编辑 profile，消息中的成员提及按完整标识匹配。
- 引擎重启前会重新检查有变更的依赖声明。依赖满足时继续重启，缺包或版本不符时显示修复命令并保留当前服务。

## 远程 Hermes 节点升级

两个连接方向均使用 WSS。请先更新引擎，在远程机器对原 profile 安装本版 `install-relay.pyz` 并重启该 profile 的 Hermes 网关。原先使用 WS 的节点需要迁移：云端连本机时，在原节点重新签发配对命令并执行含 `--fingerprint` 的完整命令；本机连云端时，在原节点更新插件生成的 WSS 配对链接。现有成员标识、项目绑定和消息历史继续使用。[远程插件安装与迁移指南](https://github.com/Xinjikang/bot-group/blob/v0.3.8/docs/guides/BOT-GROUP-RELAY-INSTALL.md)
