# v0.2.11 — 2026-11-06

本版本完善话题子代理后台任务的状态展示，并修复项目助手重复关闭已处理待办时的校验错误。

## 修复

- 话题主 agent 等待子代理期间保留思考气泡，显示“子代理正在执行后台任务”和静态指示点，历史过程与停止入口保持可用。刷新、长时间等待及回复后的空等待气泡保持同一逻辑执行；主 agent 续跑后恢复运行展示。
- 话题状态快照从本地执行账本补齐后台等待记录，父轮 final 与逻辑执行结束分别处理，回调续接沿用原执行身份。
- 项目助手再次返回已处理卡片 ID 时，按本会话服务端签发的历史卡片执行幂等关闭；未知 ID 和跨会话 ID 继续校验，其余待办保持原样。
- UI-SPEC 补齐 2.9 变更记录，测试说明明确合成接口、消息列与二次等待状态切换的覆盖范围。

实现契约见 [后台状态与待办幂等](../design/2026-11-05-topic-background-status.md)。

## 验证范围与已知问题

- 指定隔离回归 88 项通过，覆盖等待快照、执行身份、历史采集边界与 HUD 幂等；Node 前端生命周期通过。
- 发布专项 48 项通过，覆盖公开安装入口、bootstrap、源码清单、升级恢复及 Windows BAT 入口。
- 真实 Chrome 使用合成 HTTP 验证深浅主题 × 1280/390px 消息列。390px 用例隐藏两侧栏；嵌套委派由模拟回执的后端用例覆盖，浏览器验证等待、运行、再次等待和结束展示。真实网关、模型与浏览器联动的端到端行为需另行验收。
- `test_mixed_runtime_codex_dsh_busy_skip_and_resume` 在本版功能提交及 v0.2.10 基线均于同一断言失败，根因与生产影响待定位，按 [独立需求](../requirements/2026-11-06-mixed-runtime-busy-regression.md) 跟踪。
- 长等待期间沿用既有历史轮询机制；HUD 历史异常记录容错与长历史轮询成本保留为后续维护项。

测试方法、参数与隔离要求见 [测试索引](../../scripts/TEST_INDEX.md)。

## 升级

Release 安装使用“设置 → 关于 → 检查新版本”或 `upgrade.bat`。Git 源码安装更新后手动重启引擎并刷新页面。

发布资产包含源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`；操作步骤见 [发布指南](../guides/RELEASE-GUIDE.md)。
