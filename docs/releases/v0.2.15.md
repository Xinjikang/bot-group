# v0.2.15 — 2026-11-14

本版本修复 DSH 0.2.2 启动兼容和发送消息后的列表刷新。

- POSIX 凭据副本按 0600 创建，目录权限为 0700，满足 DSH 的私有凭据检查。独占创建保护竞争文件，写入失败清理本轮副本。
- DSH 0.2.2 起通过原生 headless 参数启用 Auto，在任务开始时采集预设证据，工具执行前核验审批状态。唤醒、续跑和项目助手使用一致的选择逻辑，旧版保留兼容路径。
- 消息发送成功后主动刷新列表，合并旧请求期间的新消息刷新需求，支持已读确认挂起和话题切换。
- 仓库新增晨间发送卡顿只读探针，记录进程、磁盘和系统事件，限制输出容量并核验目标进程归属。探针位于 scripts，按源码资产规则保留在仓库。

设计见 [DSH 兼容](../design/2026-11-14-dsh-v022-compatibility.md)，消息行为见 [消息发送](../engineering/MESSAGE-SEND.md)。

验证覆盖隔离单元回归、真实 JavaScript 适配器执行、Chrome 消息刷新，以及 Windows 上 DSH 0.2.1-rc.5 和 0.2.2-rc.2 的原生离线模型夹具。两版均验证命名 profile、人格继承、Auto、工具范围和实际文件读取。POSIX 权限调用通过模拟平台测试，macOS 现场验证待补充。

Release 安装通过“设置 → 关于 → 检查新版本”或 upgrade.bat 升级。Git 源码安装更新后手动重启引擎并刷新页面。安装与回滚步骤见 [发布指南](../guides/RELEASE-GUIDE.md)。
