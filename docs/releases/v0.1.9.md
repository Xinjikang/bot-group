# v0.1.9 — 2026-10-29

本版本修复 Windows 上 Hermes 0.22.x 的启动器兼容问题，并加入独立的项目助手。

## Hermes 启动与会话修复

- 修复 [#12](https://github.com/Xinjikang/bot-group/issues/12)：支持官方 Windows CMD/BAT 启动器中的固定参数及 base64 Python 入口，保留参数数组传递；自动发现补充 LOCALAPPDATA 和配置目录布局。
- 启动器解析继续拒绝多命令、控制流、未解析变量和相对可执行路径。异常提示提供具体入口信息，便于定位配置问题。
- 成员工作区和会话只读查询不再启动 Hermes 网关；已有会话查询与真正的执行启动分开处理。

## 项目助手与界面

- 顶栏常驻“项目助手”，维护 Bot 可独立选择，使用与群聊隔离的会话。支持选项和自由回答、配置提案确认、使用说明及空闲上下文重置。
- 创建向导保留维护草稿；项目详情与助手可同时操作，展开助手贴靠详情右侧并保持同高。
- 项目详情各标签等高，编辑框和成员、角色、权限列表利用剩余空间，底部操作保持可见。
- 设置页调整字段间距，明确“新建 profile”“刷新可选 Bot”和“选择 AI”文案，统一复选框样式；取消与保存并排，名称与状态文字分层显示。
- SOUL 模板入口仅在项目创建及项目详情配置中显示，HUD 新建和全局 profile 编辑隐藏该入口。

## 支持范围与升级

Hermes 网关既有实测基线为 0.22.5（bf0203a7），旧版 CLI 兼容基线为 0.21.1 和 0.21.3。本版补充 Windows 0.22.x 启动器形态的解析与真实 Python 参数传输回归；issue #12 报告的构建为 0.22.1+243.g8b9ac57。其他构建仍按实际接口及协议能力检查。

Release 安装使用“设置 → 关于”或 upgrade.bat 更新，再重启引擎。Git 源码安装更新后执行 tools/install.py repair，并手动重启引擎。项目助手需要选择模型配置并逐项目启用；维护提案经确认后生效。详情见[工程契约](../engineering/PROJECT-HUD.md)。

发布包含源码 ZIP、release_manifest.json、SHA256SUMS、releases.json、bootstrap.py 和 install.ps1 六项资产。安装及发布方法见[发布指南](../guides/RELEASE-GUIDE.md)。
