# v0.3.2 — 2026-11-23

修复网页点击“重启服务”后弹出 `signal timed out`、页面停止跟踪重启结果的问题。页面在提交前释放事件连接并记录当前实例和操作编号。收不到提交响应时持续查询本次回执；首次请求丢失时，可向同一实例补交一次相同编号的请求，引擎据此避免重复重启。

页面分别显示等待受理、服务收尾和校验新实例的进度。刷新后可继续查询。引擎返回失败时显示具体原因；只有新实例的程序目录与数据库路径核验通过才自动刷新页面。

修复旧安装的默认数据库在重启期间迁入 `data/group.db` 后被误报为重启失败的问题。重启助手按已完成的迁移记录核对新路径，并保留原路径供查阅。

Windows 安装和升级沿用原入口。配套的远程 Hermes 插件与引擎使用同一版本标签。[安装与升级指南](../guides/RELEASE-GUIDE.md)
