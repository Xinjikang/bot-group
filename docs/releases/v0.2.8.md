# v0.2.8 — 2026-11-04

本版本修复 Hermes 慢请求期间的心跳误断线，并增强会话初始化恢复和任务调度故障提示。

## 修复

- 共享连接执行 RPC 时暂停应用层心跳检查，避免心跳排在慢请求后超时、关闭整条连接。空闲连接真实超时继续执行故障处理。
- 会话创建、恢复和配置发生传输错误时，最多重连一次并按原请求编号、参数、版本及执行代次核对回执。提交消息继续由持久执行账本恢复；配置后发现会话忙碌时保留任务等待调度。
- 原生会话状态查询失败单独记录原因；持续故障提供去重提示，待处理任务保留在队列，连接恢复后继续调度。
- 断线诊断增加 RPC 方法、耗时、WebSocket 关闭码和心跳失败阶段，日志省略请求正文、凭据和远端关闭文本。

## 验证与范围

心跳与初始化修复覆盖 153 项相关用例；调度故障修复另有查询、告警去重和任务恢复回归。验证使用隔离数据库、临时目录和随机端口的合成 WebSocket 服务端。

实现契约见 [心跳与初始化恢复](../design/2026-11-04-hermes-rpc-heartbeat.md) 和 [会话恢复与调度故障](../design/2026-11-04-session-routing-recovery.md)。Hermes 运行时独立维护，本版本交付 bot-group 引擎侧修复。

## 升级

Release 安装通过“设置 → 关于 → 检查新版本”或 `upgrade.bat` 更新。Git 源码安装更新后手动重启 bot-group 引擎，加载本版本修复。

发布资产包含源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。操作步骤见 [发布指南](../guides/RELEASE-GUIDE.md)。
