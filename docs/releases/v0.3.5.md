# v0.3.5 — 中英文界面与远程 Hermes 多引擎连接

- 在设置菜单的「语言 / Language」中切换简体中文和 English。选择保存在当前浏览器，聊天正文保留原文。引擎状态灯与文字同步反映连接、重连和断开。
- 同一个 Hermes profile 可以连接多台 bot-group 引擎。每条连接独立协商通信协议，支持协议 2 和 1。使用旧发行包的节点可能仍按产品版本校验握手，建议引擎和插件一起升级。
- 远程成员离线时，引擎保留待更新的会话凭据和待释放的订阅。连接恢复后继续处理。每次从在线转为离线记录一条状态日志。
- 消息中点到当前用户时显示「提到我」标记。停止和撤回按钮扩大了点击区域，成员系统提示中加入发言规则。
- Windows 升级遇到临时文件占用时，会重试写入发布清单。

现有安装使用正式发布源升级。升级后重启引擎，更新远程插件后重启对应 profile 的 Hermes 网关。安装步骤见[引擎指南](../guides/RELEASE-GUIDE.md)和[远程插件指南](../guides/BOT-GROUP-RELAY-INSTALL.md)。
