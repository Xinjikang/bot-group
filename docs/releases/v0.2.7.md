# v0.2.7 — 2026-11-04

本版本修复运行期间反复执行数据库迁移引起的写锁竞争。该问题会导致话题发送请求等待，以及页面查询出现 `database is locked` 错误。

## 修复

- 数据库建表和迁移集中在引擎启动阶段完成。消息发送、页面查询、MCP 操作、任务池和后台轮询使用已初始化的数据库。
- Hermes 执行索引定义正确时保留现有索引；旧索引替换失败时回滚，保留原有约束与外层事务。
- 保留用户在 Bot 忙碌时发送消息的能力，以及话题发言位、权限校验、MCP 幂等回执和停止流程的原有行为。

## 验证与边界

相关隔离回归汇总为 159 项通过、1 项因系统符号链接权限跳过。对照旧版连接函数可复现持写锁时的页面查询错误；修复后同场景通过。新增并发验证覆盖 Bot 保持忙碌期间连续发送 8 条消息与 24 次并发轮询，以及运行期零 DDL、旧库升级、重复初始化和索引替换失败回滚。

具体契约见 [数据库初始化与运行流量](../design/2026-11-04-runtime-schema-boundary.md)。业务写事务仍按 SQLite 的单写者规则串行执行。

## 升级

建议尽快升级。Release 安装通过“设置 → 关于 → 检查新版本”或 `upgrade.bat` 更新。Git 源码安装更新后手动重启引擎并刷新页面。

发布资产包含源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。操作步骤见 [发布指南](../guides/RELEASE-GUIDE.md)。
