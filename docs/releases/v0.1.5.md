# v0.1.5 — 2026-10-26

本版本完善 Windows 桌面启动、浏览器页面复用和维护后的自动刷新，并修正成员候选识别与协作提示规则。

## 更新内容

- 安装和升级维护当前用户桌面的 **Bot Group** 快捷方式，使用四个圆形顶点的三棱锥图标。支持自定义安装路径、数据目录及多实例入口。
- 快捷方式、`start.bat` 和 `start.sh` 共用启动逻辑：复用健康的现有引擎，服务就绪后自动打开配置地址的页面。已有连接的 UI 或登录页时复用页面，全部关闭后重新打开；连续打开请求合并 10 秒。页面切到前台的实际效果由浏览器策略决定。
- 网页重启和升级完成新实例校验后，自动刷新当前页面加载资源；失败时保留诊断结果。维护流程保持现有浏览器入口，兼容旧版升级助手与失败恢复。
- 成员候选过滤失效或无效配置，同时保留历史登记；成员信息查询按信息缺失和任务交接需要执行，同步更新提示词及项目模板规则。

## 安装与升级

新安装使用 [README](../../README.zh-CN.md#安装与启动) 的公开安装命令。发布资产为 `bot-group-v0.1.5.zip`、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。

Release 安装通过“设置 → 关于”检查并升级，或运行 `upgrade.bat`。从旧版本升级后，刷新原有页面以启用页面登记与复用；新版本后续网页维护完成时自动刷新。Git 工作区通过 Git 更新，执行 `tools/install.py repair` 同步就绪记录后手动重启引擎。模板更新作用于后续生成与引用，已有项目规则由维护者按需更新。

## 验证范围

启动与页面复用的 43 项单元/集成回归通过，真实 Chrome、实际 BAT 与临时桌面快捷方式覆盖首次打开、快速重复、登录页、后台页、刷新、多页面及全部关闭后重新打开。重复启动时引擎实例保持一致；维护重启仍更换实例。浏览器焦点验证覆盖激活事件调用，实际前台切换由浏览器控制。

发布构建核对 Git 文件、源码清单、图标与页面登记资源、VERSION 和全部资产摘要。公开安装验收使用独立端口及数据目录，验证匿名下载、重复安装、BAT 启停、HTTP 页面与默认升级检查。方法见 [测试索引](../../scripts/TEST_INDEX.md)，证据保存到项目主目录 `reports/tests/v0.1.5/2026-10-26-release/`。
