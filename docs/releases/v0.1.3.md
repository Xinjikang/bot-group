# v0.1.3 — 2026-10-25

本版本修复 Windows Hermes 唤醒进程探测和维护模块包冲突，并完善项目成员管理。

## 更新内容

- Windows 进程查询改用 Toolhelp 筛选与 psutil 参数读取，支持缺少 WMIC 的系统。Hermes 唤醒、停止及 MCP 进程回查共用查询逻辑；保留权限失败、进程退出和 PID 复用时的保护。
- 安装、升级和服务维护实现迁入 `engine.maintenance`，解决与 Hermes 顶层 `tools` 包的冲突。更新检查与 Hermes 会话创建、恢复可在同一引擎中共存，现有 `tools/` 命令和 BAT 入口保持兼容。
- 发布包保留旧升级器需要的兼容入口，独立 `bootstrap.py` 继续支持基础 Python 安装。升级按清单移除旧维护包文件，失败后恢复旧版并重新启动服务。
- 成员卡片增加更多菜单和按项目移出操作，统一卡片布局。移出前检查进行中的任务和会话，保留 Bot 全局配置及历史记录；角色删除确认明确说明职责与权限影响。

## 安装与升级

新安装执行 [README](../../README.zh-CN.md#安装与启动) 中的 PowerShell 或 CMD 命令。六项资产为 `bot-group-v0.1.3.zip`、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。

v0.1.2 Release 安装可在“设置 → 关于”检查并升级，完成后刷新页面。v0.1.0/v0.1.1 安装继续使用原目录 `upgrade.bat`，成功后运行 `start.bat`。自定义数据目录沿用原有 `GROUP_DATA_DIR`。

Git 工作区更新后，使用基础 Python 执行 `tools/install.py repair` 同步依赖与就绪记录，再运行 `start.bat` 并刷新页面。持有旧进程查询代码的 MCP 宿主需要重新加载；Hermes 网关持有的 MCP 进程通过网关重启更新。

## 验证范围

维护包修复的 231 项回归全部通过，覆盖真实 Hermes 源码在两种加载顺序下的会话操作、旧版实际升级助手迁移、失败回滚、安装发布和服务启停。本机重启后健康、页面、版本及更新接口正常；进程探测三次耗时为 23–37 毫秒，耗时随机器和进程数量变化。

进程查询回归覆盖缺少 WMIC、未知状态恢复、PID 复用及隔离队列到 stdio MCP/HTTP 的执行链路。目标机器的真实模型调用仍需现场验证。测试方法见 [测试索引](../../scripts/TEST_INDEX.md)，发布资产及公开安装验收证据保存在项目主目录 `reports/tests/v0.1.3/2026-10-25-release/`。
