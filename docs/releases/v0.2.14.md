# v0.2.14 — 2026-11-10

本版本修复数据库锁竞争引起的全站响应停顿，并完善 Hermes 模型继承、后台进程等待和项目助手续跑。

## 修复

- 认证中的同步 SQLite 操作整体在线程池执行，连接在同一工作线程创建、使用及关闭。心跳写入迁入同步端点，在写锁内复查权限、执行轮次及终态；锁等待超时返回 HTTP 503 和 `Retry-After: 1`。WAL 按数据库实例初始化，保留失败重试与逐连接配置。
- Hermes 唤醒逐字段解析项目覆盖及当前 profile 的模型、供应商和推理强度，旧会话通过官方接口应用当前策略，保留会话和历史。
- Hermes 原生后台终端进程等待保持原任务和执行归属，按可信完成通知续跑；等待期间保留过程气泡与停止入口，完成全部后台工作后统一结束。
- 项目助手处理暂缓提案后先完成关闭，再提交续跑消息，保持界面与服务端待办状态一致。

实现与约束见 [认证数据库隔离](../engineering/AUTHORIZE-LOCK-ISOLATION.md)、[模型继承](../design/2026-11-09-hermes-model-inheritance.md) 和 [后台进程等待](../design/2026-11-10-hermes-background-process-wait.md)。

## Hermes 兼容范围

网关版已有实测基线为 Hermes **v0.22.5 / `bf0203a7`**；旧版 CLI 已验证 **v0.21.1 / `cdf4c765`** 和 **v0.21.3 / `afc3b7c6f3`**。低于 0.22.x 的已验证版本继续使用本地 CLI 子进程、按 profile/会话匹配的进程检查及每次执行的 MCP 注入；网关版使用官方会话协议、admission 回执与会话级 MCP。后台完成通知能力按原生接口检查。其他版本以实际接口和隔离运行证据确认，详见 [兼容契约](../engineering/HERMES-COMPATIBILITY.md)。

## 验证边界

锁竞争修复独立回归 77 项通过，真实隔离 HTTP/SSE 测试中持锁 297ms 期间读请求在 16–31ms 返回，心跳超时重试与资源释放通过。该测试使用合成执行凭据及隔离数据库，模型继承和后台等待采用隔离数据库、模拟 RPC 与既有浏览器证据；生产现场与外部模型链路单独观察。

发布前执行源码资产、安装升级和本版相关回归；发布后从公开下载入口验证首次安装、重复安装、BAT 启停及默认升级检查。原始证据保存在项目测试报告目录。

## 升级

Release 安装使用“设置 → 关于 → 检查新版本”或 `upgrade.bat`。Git 源码安装更新后手动重启引擎并刷新页面；已运行的模型轮次沿用当前策略，下次唤醒应用新配置。

发布资产为源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`。操作步骤见 [发布指南](../guides/RELEASE-GUIDE.md)。
