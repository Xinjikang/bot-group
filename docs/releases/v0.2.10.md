# v0.2.10 — 2026-11-04

本版本修复 DSH 项目助手的人格继承、启动环境与工具完整性校验，并修复 HUD 空显示名的重复提交校验。

## 修复

- 助手专用指令通过原生提示词段追加，保留 bundle、profile patch、HOME patch 的有效人格、既有人格后缀及配置覆盖顺序。desktop 延续现有 headless 后台适配。
- 清理继承的 DeepSeek API key 和 DSH profile，显式绑定所选 HOME、原生工具模式与 workspace-write。凭据继续由所选 HOME 的原生配置解析，已安装 Auto 的会话审批与证据校验保持有效。
- 等待八项必需工具全部注册后设置 agent 工具范围，核验实际清单并输出结构化证据。缺失工具在模型执行前报错，MCP 延迟注册有 10 秒等待期限，取消及时退出。
- HUD 配置更新在相同值的提前返回之前验证输入，空显示名及纯空白提交返回 400，失败保持项目与会话修订。
- v0.2.9 发布文档分别列明定向检查、完整回归及原生验证的覆盖范围。

实现契约见 [DSH 执行恢复与项目助手](../design/2026-11-04-dsh-execution-recovery-hud.md) 与 [项目助手工程说明](../engineering/PROJECT-HUD.md)。

## 验证

隔离回归覆盖 DSH/HUD、执行生命周期、进程查询、重启恢复、配置并发及权限；原生验证使用已安装 DSH、临时 HOME、合成模型与独立 MCP，覆盖五种人格来源/覆盖场景、污染环境和缺失工具。八项工具清单、原有人格后缀、Auto preset、文件读取和配置工具调用均有运行证据，外部模型调用为零。正式发布验证覆盖安装、升级和 Windows BAT 入口。

测试方法、参数与隔离要求见 [测试索引](../../scripts/TEST_INDEX.md)。

## 升级

Release 安装使用“设置 → 关于 → 检查新版本”或 `upgrade.bat`。Git 源码安装更新后手动重启引擎并刷新页面。

发布资产包含源码 ZIP、`release_manifest.json`、`SHA256SUMS`、`releases.json`、`bootstrap.py` 和 `install.ps1`；操作步骤见 [发布指南](../guides/RELEASE-GUIDE.md)。
