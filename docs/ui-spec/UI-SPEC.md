# bot-group UI 规范

“查看 / 引用 SOUL 模板”仅在项目创建向导和项目详情的 profile 配置中显示。HUD 新建 profile 及全局 profile 编辑隐藏整个模板工具栏和引导提示，全局入口不借用顶栏当前项目作为模板上下文。

HUD 默认名称为“项目助手”，名称采用 13px、600 字重，后续状态采用 12px、400 字重及次级文字色。设置页字段组间距 22px，标签与输入间距 8px；“新建 profile”和“刷新可选 Bot”位于 AI 选择器下方。复选框复用弹窗的 15px 尺寸和主题选中色。设置页底部并排显示取消与保存，取消返回对话并放弃当前未保存选择，顶部返回入口隐藏。

版本：2.1。适用范围：Web 群聊与任务管理界面。前端开发维护，审查员核验；变更随代码提交并记录任务依据。

本规范整理现有实现。主题变量与基础布局见 [index.html](../../frontend/index.html)，主题覆盖见 [appearance.css](../../frontend/appearance.css)，向导及弹窗样式见 [dialogs.css](../../frontend/dialogs.css)。新增界面复用现有变量和组件；具体业务交互见 [文档索引](../INDEX.md)。

启动入口复用已连接的本机页面，登录页和后台标签页均参与登记。页面收到激活请求后尝试唤回，浏览器控制实际前台焦点；所有页面关闭后启动入口重新打开页面。详细协议见 [启动与刷新](../design/2026-10-26-startup-ui.md)。

## 视觉与主题

界面使用深蓝与金色的视觉语言，支持深色、浅色两套主题。浅色主题采用灰蓝面板与金色强调；消息区保留行星或用户背景图，并通过遮罩与气泡背景保证文字阅读。浅色最终值以基础样式之后加载的 appearance.css 覆盖为准。

| 语义变量 | 深色 | 浅色 |
| --- | --- | --- |
| `--bg` | `#0a0e1a` | `#dce4ec` |
| `--card` / `--card-2` | `#111a2e` / `#16213a` | `#edf2f6` / `#e2eaf0` |
| `--fg` / `--fg-2` / `--fg-3` | `#e8e6df` / `#9aa3b5` / `#7c86a0` | `#25384a` / `#4e6274` / `#596d7e` |
| `--accent` / `--accent-2` | `#c9a24b` / `#e8c97a` | `#a17c39` / `#77551f` |
| `--cyan` | `#6fd6e0` | `#0e7fa8` |
| `--ok` / `--warn` / `--danger` | `#4bc88a` / `#d9a13c` / `#e05c6a` | `#237343` / `#885b12` / `#b33749` |

边框、悬停、投影等使用 `--border`、`--border-soft`、`--hover`、`--glow`。状态表达同时保留标签、说明或图标。消息气泡和思考内容有专门的主题覆盖，调整时检查实际叠加背景，见 [气泡颜色](../engineering/BUBBLE-COLOR-2026-10-17.md)。

## 文字、尺寸与间距

- 基础字体为 Segoe UI、Microsoft YaHei、sans-serif，正文基准 14px；一般控件 13px，辅助信息多为 11–12px。装饰性栏目标题沿用 Georgia / Microsoft YaHei，表单与正文沿用系统字体。
- 面板基本圆角 `--radius: 12px`；普通表单控件圆角 10px、高度 36px。项目向导输入与选择控件高度 40px，向导标题 19px、区块标题 17px。
- 主布局内边距与栏间距为 14px；普通弹窗内边距 26px。项目向导正文内边距 24px 28px，资源卡片内边距 18px、间距 16px。
- 工作区资源表单的测试数据目录标签与输入框间距为 7px；独立资源弹窗的状态提示上方留 12px，底部按钮区上方留 18px，按钮间距为 8px，靠右排列并支持窄屏换行。
- 新组件按所在区域复用对应尺寸，具体例外记录在本文件，避免同一区域出现重复的视觉规则。

## 布局与滚动

主界面由顶栏、话题栏、消息栏、任务栏组成，消息栏弹性占据剩余空间。栏目采用纵向 flex、正文独立滚动；缩放和折叠沿用现有布局逻辑。主界面保留高密度协作布局，窄屏策略按具体区域检查。

- 长消息、任务列表及详情正文在自己的容器滚动；标题、筛选、导航、输入区和关键操作维持可见或可触达。
- 任务详情和创建/导入向导采用标题、可滚动正文、操作区分层；固定操作与正文保留足够空间。
- 600px 以下顶栏允许换行，项目选择占独立一行；520px 以下项目向导收窄边距，权限表单调整列数。成员卡片在 420px 以下采用更紧凑内边距。
- 界面修改验证桌面与 390px 窄屏，涉及断点时补查断点两侧。长名称、长路径和多按钮场景纳入检查。

滚动和刷新约定见 [固定控件](../engineering/FIXED-PANEL-CONTROLS.md)、[刷新范围](../engineering/FRONTEND-REFRESH.md)。

## 组件与状态

项目详情的成员、角色和权限列表填满各标签页剩余高度，列表内部滚动。顶部说明及操作区保持原位，角色状态和权限保存区位于列表下方。

项目详情的 AGENTS.md 编辑框填满该标签页剩余高度，保存按钮位于其下方；顶栏、窗口和其他标签页沿用原有布局。

项目详情各标签共用固定窗口高度 `min(740px, 100dvh - 100px)`。标题和标签栏固定，标签内容在内部滚动；切换基本信息、AGENTS.md、成员、角色、权限时窗口位置和尺寸保持一致。

项目详情与 HUD 可持续交互。点击 HUD 的展开、选项、输入、发送或设置，详情及当前标签保持打开，未保存字段保留。HUD 优先使用详情中正在查看的项目，详情关闭后回到顶栏当前项目。展开时保持详情的位置和尺寸，HUD 贴靠详情右侧，间距 8px，顶部对齐、高度相同；详情内容改变高度时 HUD 同步跟随，正文内部滚动。收起后 HUD 回到顶栏原位置。右侧剩余宽度不足 300px 时使用原有浮层布局，详情仍保持原位。Escape 在 HUD 内只收起 HUD。常规锚定及居中弹窗的外部点击关闭规则豁免 HUD 内部点击。

项目维护 HUD 固定在顶栏中间，紧凑态显示维护 AI 与状态。展开内容随场景切换：交流显示连续对话，待答问题显示题目与选项，变更显示确认提案，用法咨询显示分步说明。主要场景始终显示 AI 正文，提问原因默认折叠；完整往来使用“对话记录”入口，并可返回当前场景。选项点击即发送，已有补充一起发送；成功后选项消失并保留为用户消息，失败保留完整回答。输入与发送固定底部。已确认资料、项目切换和设置收在更多入口。浏览旧消息时新回复通过“查看最新回复”提示。HUD 外层使用半透明渐变玻璃、26px 背景模糊、细边高光和轻阴影，选择项采用简洁分隔线；深浅主题保持正文清晰。Escape 收起并返回触发按钮；同一问题手动收起后保持收起。390px 窄屏采用两侧 12px 留白。创建向导打开时 HUD 随向导进入同一弹窗层，关闭后恢复全局位置。详见 [项目维护 HUD](../engineering/PROJECT-HUD.md)。

设置菜单各项使用 16px 线条图标，与文字间距 10px，继承当前文字颜色及禁用反馈；装饰图标对辅助技术隐藏。主题切换同步切换太阳/月亮图标，重启状态更新保留图标及对齐。

右上角依次展示更新提示、用户称呼、设置菜单及连接状态。长称呼截断并提供完整 title；窄屏允许顶栏换行。设置菜单集中展示称呼、背景、主题、重启与关于，浮层保持在主内容之上，支持 Escape、焦点离开和点击外部关闭。重启进度持续显示在连接状态处。成员启停胶囊显示“启用 / 停用”，以文字、颜色和圆点表达状态，保留 switch 语义及请求中禁用反馈。

思考条以引擎 `/thinking` 的运行状态为权威，不按本地计时推断。执行状态无法确认（manual 或查询失败）时，思考条保持停住并显示事实状态：「停止请求已发送，结束状态确认超时」（本页发起过叫停）或「执行状态查询失败」；状态行与标题使用 `--danger`（浅色主题提高到 `#ff9fa9`），不再显示「思考中」。停止按钮保留，是否再次点击由用户决定；文案只报告操作失败或确认超时，不要求用户接手处理。叫停请求本身失败时提示「停止失败：原因」。取消请求已发出、服务尚未确认结束时显示「正在取消…」。停住状态只提示一次，展开仍可查看保留的过程内容。

| 组件 | 约定与检查项 |
| --- | --- |
| 主操作与图标按钮 | 使用主题强调色和可访问名称；提供悬停、焦点、禁用及提交中反馈 |
| 表单 | 明确标签、适用范围和保存动作；失败保留已填内容，提交中防止重复执行 |
| 话题、成员和任务条目 | 当前项、状态和可用操作清晰；长标题换行或提供完整内容入口 |
| 弹窗与向导 | 正文滚动、操作可见；核对键盘焦点、关闭与返回后的状态 |
| 消息与输入区 | 保留草稿、选区、阅读位置及已展开内容，图片比例与文本边界清晰 |
| 空态与失败 | 说明当前状态、原因及可用操作；权限不足、断线和业务空数据分别表达 |

对话框中有填写限制的字段，在输入、离焦或提交校验发现错误时使用 `--danger` 红色文字说明具体要求。错误靠近对应字段，设置 `aria-invalid` 和 `aria-describedby`，修正后清除；输入法组词期间保持输入稳定。必填、长度、格式、数字范围及整数约束复用 `dialogs.js` 的字段提示，业务校验和服务端失败通过显式错误状态显示。关闭重开清理过期字段错误。

已有 Codex 成员的沙箱及智能审批配置提醒分别使用 `--warn`，选择候选后显示，切换候选或创建方式时更新。两项提醒保持加入按钮可用，沿用同页的创建入口。新建 Codex 表单说明统一启用智能审批、沙箱及项目目录授权。

详情“选择成员”窗口与新建项目向导统一使用圆角成员卡片：圆角 12px、边框 `1px solid var(--border-soft)`、背景 `var(--card-2)`、内边距 14px 16px、卡片间距 12px。卡片内名字与宿主 / profile 分两行展示，行间距 3px，辅助信息使用次级文字颜色，选中时边框使用 `var(--border)`。

## 验证与维护

角色新增授权直接更新选择。项目权限页仅在取消已保存的角色授权时提示影响，提示包含角色、权限名称及保存后生效的边界；取消尚未保存的新增授权保持安静。新建/导入向导仅在角色权限方案减少时提示核对职责，并注明最终提交后生效。

项目成员卡片保留启停、角色选择和工作区操作；更多菜单收纳编辑 profile、重置会话及危险色的移出项目。危险项使用分隔线，菜单支持方向键、Home/End、Escape、外部点击及视口边界避让。移出确认框初始聚焦取消，检查与提交期间禁用提交，阻塞事项提供具体处理入口；子确认框内点击保持项目详情打开。交互契约见 [项目成员移除](../engineering/PROJECT-MEMBER-REMOVAL.md)。

“换背景”弹窗以顶栏始终可见的“设置”按钮为定位参照；首次打开、背景加载及保存/恢复提示更新后保持右侧定位，并按视口边界避让。

“关于”显示当前运行代码身份：Release 安装显示版本号，Git 源码显示 tag/提交号并标注本地修改。缺少本地正式 tag 的源码显示开发版提交号，更新说明提示按提交记录核对差异。

“关于”提供“检查新版本”，点击后立即检查并显示等待、失败可重试或当前最新状态。有更新时显示目标版本及升级按钮；右上角新版本提示与该按钮使用同一个升级确认框，说明暂停服务、备份、自动启动、自动刷新与失败恢复。Git 工作区和缺发布清单的安装显示具体原因，升级按钮禁用。升级中禁止重复提交及同时重启；进度在关于窗口和连接状态显示，断线后持续核对回执，刷新页面可恢复监控。重启和升级完成新实例校验后清除监控记录，自动刷新当前整页加载资源；页面失败时保留错误提示。

“重启服务”确认框说明 Hermes 网关执行继续运行、服务启动后接回原执行；Codex 等本地执行最多等待 120 秒收尾，超时后停止。重启期间暂停新任务派发与工具写入，服务恢复后自动刷新界面。进度分别显示收尾本地执行、停止本地执行及等待服务启动。前端核对重启回执的上限为 5 分钟，超时保留回执；失败回执显示「重启失败：原因」及 logs/service-restart.log 路径。重启失败后是否再次点击由用户决定。

项目向导第 5 步与详情“添加成员”复用勾选列表，顶部提供“创建 profile”和“刷新列表”，列表仅展示尚未加入当前项目的 Bot。刷新后和批量加入部分成功后，已入组成员从候选列表移除；列表为空时保留创建和刷新入口。创建独立窗口内选择宿主，提前说明取消选择后 profile 保留；创建成功返回列表、自动勾选并保留已有选择。详情“加入项目”和向导最终确认分别完成入组。创建窗口和列表底部动作保持滚动可达，窄屏至少验证 390px。

前端变更按任务范围检查深浅主题、默认及自定义背景、长内容、关键组件状态、键盘焦点和窄屏。可访问性检查包括标签、对比度与操作可达性；本文记录源码基线，具体达标结论以实际验证证据为准。

Hermes 创建窗口自动继承模型凭证，配置来源下使用辅助文字说明默认来源及消息渠道隔离，省去认证勾选框。Bot 异常沿用系统通知样式，正文为名称与统一分类文案，刷新后保留。主动停止沿用已有弹窗提示。契约见 [执行异常反馈](../engineering/EXECUTION-ERRORS.md)。
