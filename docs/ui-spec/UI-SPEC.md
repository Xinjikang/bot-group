# bot-group UI 规范

远程节点管理打开时显示“正在读取远程节点”。只有节点接口成功返回空列表后才显示“暂无远程 Hermes”。思考气泡在远程历史记录准备期间保留已有内容和读取游标，按服务端给出的间隔重试。单页同时最多执行两项思考轮询，给前台交互保留连接。

远程节点的本机监听选项依次显示网络用途、网卡名称、IP 和地址族。重复的名称只显示一次。公网 IPv4 和 IPv6 均标为「公网」，Hyper-V 虚拟交换机标为「Hyper-V 本机虚拟机」，Mihomo 接口从候选项中过滤。实际监听摘要展示已生效的网络和地址端口。

节点卡的「允许来源 IP」逐项显示网络说明。使用本次引擎运行期间该成员最近一次已认证入站连接的端点识别接口；其余地址按可判定的地址范围展示「公网」「内网」或「共享地址」等说明。

“成员与目录”先显示远程 Hermes 成员卡片，再逐行更新远程工作会话状态。查询中和状态未知时均可使用成员的常规操作，重置会话在确认已有会话后启用。状态回填保留输入焦点、草稿与展开的菜单。

项目成员的模型设置在保存范围旁提示“保存后，下次唤醒该成员时应用”。Hermes 换模失败时，项目消息区显示仅点名用户的系统通知，说明目标模型、当前模型、失败原因和新建会话命令。连续唤醒同一会话、同一目标时只提醒一次。

项目助手的“暂不处理”在点击时立即撤下目标提案及其行动提醒，更新待办数量，保留当前标签、其他卡片及输入草稿。随后后台提交撤下决定并让助手继续讨论。提交中显示“正在发送…”，成功后卡片保持关闭；失败重新读取服务端状态，尚未撤下时恢复卡片并显示错误，允许重试。

项目助手通过原生工具完成文档工作后，在 HUD 对话页显示文件路径、修改摘要和待确认事项，长文保存在项目文件中。历史文档提案显示文件名与兼容说明。配置工具保存后同步仍与原值一致的详情或向导字段，用户另外编辑过的输入保留；同修订号的配置更新也应触发状态刷新。连续更新按顺序逐步应用，漏过中间轮询时补齐全部步骤；重复轮询保持幂等，未保存输入逐步按修改前值保护。旧备注待办归档后的状态标识变化也触发刷新。

助手响应“打开配置/角色/成员/权限页面”时，HUD 打开当前项目的既有配置窗口并定位对应标签；已打开的同一项目窗口保持未保存输入，同一导航请求在当前标签页只执行一次，过期请求保持静默。原生工具执行期间显示具体阶段，工具参数与结果正文保持在原生运行时。角色字符异常显示具体字段、可见转义值和字符位置。

项目助手消息区固定提供“对话消息”“待办事项”两个标签，默认打开对话消息，待办标签显示当前项目卡片数量。切换标签保留对话与卡片输入，轮询保持当前标签，切换项目回到对话消息。标签支持方向键与 Home/End。待办卡片数量不设上限，每张保留自己的选项、自由回答或确认/暂不处理操作。处理一项后其余卡片保持显示；空列表显示“当前项目暂无待办事项。”。卡片采用主题背景、细边框、12px 圆角和 14px 内边距，输入框采用 10px 圆角。

“有待处理事项”对应当前会话中等待用户回答或确认的卡片。成员负责的修改、提交、测试和索引更新作为普通对话内容；旧数据只有 pending 提醒而没有实际卡片时保持普通状态。

对话消息页最多显示最近一条用户消息及其后的最新助手回复，按用户、助手顺序排列；用户消息存在时显示，采用 12px 次级文字色。发送成功后更新本轮消息，等待回复时显示新用户消息。使用说明随助手回复展示；问题、确认提案与行动提醒统一以独立卡片展示在待办页。历史及系统确认记录保存在后台。

项目助手按分析结果的提醒分类控制自动展开。需要用户当前决策、授权、提供必要资料或处理外部阻塞时，生成具体行动卡片并自动展开；普通待办保持原有展开状态，收起时显示“有待处理事项”。自动展开保持正在阅读的标签。问题、可选建议及配置提案本身只产生待办提示，旧记录按普通待办处理。手动收起同一行动后，在当前标签页刷新仍保持收起；新的行动可再次提醒。提醒、数量与卡片严格限定当前项目或当前创建草稿，项目助手轮询只读取当前会话。

项目助手确认卡片标题为“以下建议尚未保存”。配置修改说明保存位置为项目设置或创建向导草稿；旧备注另组显示为历史记录，仅供当前助手查看；存在旧记录时在更多菜单显示“历史备注”，长期记忆沿用所选 Bot 的原生机制。每项按“当前内容 / 建议改为”纵向对照，缺省值和未知旧值分别标注，长路径换行。确认按钮说明实际动作，旁边提供“暂不处理”；保留自由输入调整建议的入口。对话正文避免重复卡片全文，沿用现有主题、宽度与场景切换。

HUD 设置采用两个独立卡片：第一张包含 AI 选择及新建/刷新入口；第二张包含空闲重置时间与启用说明。已有项目使用本项目保存的助手配置；新建/导入项目使用独立草稿，初始显示助手选择入口，由用户为新项目选择并保存。恢复已有草稿时保留该草稿已保存的助手。全局预选功能移除，历史预选值停止参与选择。卡片使用主题背景、细边框、12px 圆角和 14px 内边距。取消与保存并排置于卡片外。

“查看 / 引用 SOUL 模板”仅在项目创建向导和项目详情的 profile 配置中显示。HUD 新建 profile 及全局 profile 编辑隐藏整个模板工具栏和引导提示，全局入口不借用顶栏当前项目作为模板上下文。

创建 profile 时，模板入口与“更多设置 → 个人指令”的标题、正文同组折叠。个人指令区域顶部间距为 20px，标题下的模板按钮和提示共用独立一行，横向排列且垂直居中，编辑框位于下方；桌面与 390px 窄屏均保持按钮与提示同一行。标签显示宿主对应内容：Hermes 为 SOUL.md，Codex 为 AGENTS.md，DSH 为人格。模板引用填入该编辑框，允许继续修改。

HUD 默认名称为“项目助手”，名称采用 13px、600 字重，后续状态采用 12px、400 字重及次级文字色。设置页字段组间距 22px，标签与输入间距 8px；“新建 profile”和“刷新可选 Bot”位于 AI 选择器下方。复选框复用弹窗的 15px 尺寸和主题选中色。设置页底部并排显示取消与保存，取消返回对话并放弃当前未保存选择，顶部返回入口隐藏。

版本：2.25。适用范围：Web 群聊与任务管理界面。前端开发维护，审查员核验；变更随代码提交并记录任务依据。

主消息输入框在当前项目/话题正在发送时，将发送按钮显示为“发送中…”并禁用，表单设置 `aria-busy=true`；成功或失败后恢复。已保存的普通用户话题消息在气泡时间旁显示“已发送”，沿用消息元数据的字号与次级文字色。文本保持可编辑，成功仅清除仍对应本次目标和文本的草稿，失败保留输入。切换目标按该目标的发送状态更新按钮，已关闭话题保留禁用状态。

主消息输入框按实际排版高度伸缩，包含软折行、空行和末尾的新空行。删短或成功发送并清空当前草稿后回缩。上限根据消息栏空间计算，为聊天记录保留可阅读、可滚动的区域；封顶后仅文字区滚动，发送与添加图片入口不随文字滚动。`Alt+回车` 插入换行后立即完整显示当前光标行，只滚动必要距离，不跳到文末或移动聊天列表的阅读位置。适配窗口高度和消息栏宽度，保留原有发送、点名和附件操作。验收场景见 [主消息输入框设计](../design/2026-11-21-main-message-composer.md)。

话题处于子代理等待阶段时保留思考气泡，标签为“子代理正在执行后台任务”，指示点静止，历史过程和停止按钮保持可用。空内容说明为“子代理正在执行后台任务，完成后主 agent 将继续处理。”；主 agent 续跑后恢复“思考中”和动态指示点，逻辑执行结束后沿用完成展示。刷新、长时间等待及嵌套委派保持同一执行的状态，回复后的等待气泡继续可见。深浅主题复用思考组件样式，390px 消息列完整展示标签及停止入口。

工作或话题会话等待带完成通知的后台进程时保留气泡，标签为“后台进程正在执行”；进程与子代理同时等待时使用“后台任务正在执行”。空内容使用对应标签并补充“，完成后主 agent 将继续处理。”。指示点、历史、停止入口、刷新及续跑沿用上述组件规则，等待与回调保持同一个逻辑执行。

Hermes 网关模式在顶栏引擎状态旁显示只读状态点和 12px 文字，子进程模式完全隐藏且释放布局空间。状态标签为“待连接 / 连接中 / 已连接 / 离线 / 连接异常 / 需要重启 / 状态未知”，统一保留 Hermes 网关前缀；已连接采用成功色，连接中和需要重启采用警示色，连接异常采用危险色，其余采用次级文字色。组件保持普通文本，无点击、详情或影响范围。业务空闲释放显示待连接，引擎失联或状态过期显示状态未知。深浅主题共用语义颜色变量，390px 窄屏保留完整 Hermes 网关标签。相邻引擎状态表示页面与 bot-group 引擎的 SSE 连接，显示“引擎连接中… / 引擎已连接 / 引擎断线重连中… / 引擎已断开”。

本规范整理现有实现。主题变量与基础布局见 [index.html](../../frontend/index.html)，主题覆盖见 [appearance.css](../../frontend/appearance.css)，向导及弹窗样式见 [dialogs.css](../../frontend/dialogs.css)。新增界面复用现有变量和组件；具体业务交互见 [文档索引](../INDEX.md)。

启动入口复用已连接的本机页面，登录页和后台标签页均参与登记。页面收到激活请求后尝试唤回，浏览器控制实际前台焦点；所有页面关闭后启动入口重新打开页面。详细协议见 [启动与刷新](../design/2026-10-26-startup-ui.md)。

## 文字、尺寸与间距

- 基础字体为 Segoe UI、Microsoft YaHei、sans-serif，正文基准 14px；一般控件 13px，辅助信息多为 11–12px。装饰性栏目标题沿用 Georgia / Microsoft YaHei，表单与正文沿用系统字体。
- 面板基本圆角 `--radius: 12px`；普通表单控件圆角 10px、高度 36px。项目向导输入与选择控件高度 40px，向导标题 19px、区块标题 17px。
- 主布局内边距与栏间距为 14px；普通弹窗内边距 26px。项目向导正文内边距 24px 28px，资源卡片内边距 18px、间距 16px。
- 工作区资源表单的测试数据目录标签与输入框间距为 7px；独立资源弹窗的状态提示上方留 12px，底部按钮区上方留 18px，按钮间距为 8px，靠右排列并支持窄屏换行。
- 新组件按所在区域复用对应尺寸，具体例外记录在本文件，避免同一区域出现重复的视觉规则。

远程节点卡片提供「删除节点 / Delete node」。确认框说明断开连接、清除配对和来源绑定、停用项目成员的影响。取消后保留卡片，确认成功后刷新列表。节点有待结束的执行时显示原因。

## 界面语言

界面支持简体中文（默认）与 English 两种语言，切换后立即生效，选择持久化到本地存储，重新打开沿用。语言入口在设置菜单「语言 / Language」，弹窗内提供「简体中文」「English」两个选项；标签始终双语呈现，首次打开中文界面的英文用户也能找到。

- 界面文案统一从 `frontend/i18n.js` 集中词表取。静态元素用 `data-i18n`（及 `data-i18n-placeholder`、`data-i18n-title`、`data-i18n-aria-label`）标记；动态文案在渲染时调用 `t("<key>")`。聊天、设置、管理页的按钮、标签、提示、空态、状态文案均随语言切换立即更新。
- 已发送的消息正文、话题/需求/任务标题、成员显示名等服务器数据保留原文，不参与翻译；消息协议标记（如 `[收口]`）按数据对待，不随语言改变。
- 思考气泡停止按钮（`.tb-stop`）留在气泡头部原位（margin-left:auto 靠右），可见文字「停止 / Stop」+ 图标，红色（--danger）高对比、600 字重、12px、背景透明，悬停时描边变红，点击区不小于 40×26px；title/aria 用「停止 {名字}」（stop_member）。
- 消息正文中的 @ 点名（`.msg-content .mention`）使用青色加粗文字，背景透明。点到当前用户（mentions 含 `user`）时，消息头部另显示「提到我 / Mentions you」徽章（`.tag-mentions-you`），使用青色文字、淡青底色和描边。徽章随界面语言切换，消息正文保留原文。
- 消息行的「撤回」按钮使用 13px 文字，按钮最小高度为 28px，左右内边距各为 10px。
- 切换语言触发 `ui-language-changed` 事件，各动态面板按当前语言重新渲染；消息区在语言变化时整体重建界面文案，同时继续保留正文与思考内容。打开中的弹窗在切换时关闭，重新打开按当前语言构建，避免一次性渲染的旧文案残留。
- 懒创建元素（切 tab 才渲染的卡片、点击才创建的弹窗、composer 工具栏等）在模板中直接用 `t()` 按当前语言求值，不能依赖 `data-i18n` 默认值；切语言后由 `ui-language-changed` 触发其刷新（如 `refreshImageEditors()`）。
- 动态写入的属性同样属于界面文案：JS 直接赋值的 `title`/`aria-label`/`placeholder`（如按钮提示、读屏标签、错误前缀）不受 `data-i18n-*` 标记保护，写入方必须监听 `ui-language-changed` 按当前语言重设；静态 HTML 属性值含中文时必须带对应 `data-i18n-*` 标记。
- 拼接点的标点也随语言：括号、冒号、句号、列表分隔等不得在拼接点写死全角；统一使用标点词条（`open_paren`/`close_paren`/`colon`/`sentence_end`）或 `workspace_sep` 列表分隔。英文下出现全角标点与出现中文等同，属未接词表残留。
- 新增或修改界面文案后提交前必须跑静态兜底扫描 `py -3.10 -X utf8 -B scripts/check_ui_cjk.py`：对 frontend 全部 JS 与 index.html 检查未接词表的硬编码中文与 CJK/全角标点（豁免注释、词表、t() 词条 key、data-i18n 属性及元素 fallback、双语语言入口与服务器数据；属性值含中文或全角标点时须带对应 data-i18n-* 标记），有命中不得提交。
- 语言选择按各浏览器本地保存；词表只收录 zh-CN 与 en，不扩展其他语言。
- 界面修改验证中英文两套文案、切换立即生效、重开沿用与 390px 窄屏；已发送消息原文一致。

## 布局与滚动

创建/导入向导的项目助手与项目详情共用右侧贴靠规则：窗口原位保留，助手展开时右侧间距 8px、顶部对齐且等高，正文独立滚动；右侧可用宽度不足 300px 时沿用浮层。收起及 Escape 保留向导和已填字段，关闭向导后助手恢复全局位置。

主界面由顶栏、话题栏、消息栏、任务栏组成，消息栏弹性占据剩余空间。栏目采用纵向 flex、正文独立滚动；缩放和折叠沿用现有布局逻辑。主界面保留高密度协作布局，窄屏策略按具体区域检查。

## 组件与状态

Hermes 网关授权卡片位于消息列表与输入区之间，显示 Bot、项目/话题、操作及原因。只呈现 Hermes 返回的授权选项，本会话与长期授权额外确认作用范围；提交时禁用按钮并显示状态，失败保留原因，失效快照禁用操作。命令和编辑详情按纯文本换行展示。消息栏可用宽度小于 320px 时改为底部浮层，两侧及底部留 12px，高度最多 45dvh，内部滚动。按钮复用主题、10px 圆角和至少 36px 高度，提供键盘焦点及禁用反馈。

本机目录选择沿用系统窗口：Windows 原生选择器、macOS choose folder、Linux tkinter。取消保持原路径，窗口不可用或超时显示明确错误，并保留手动输入路径入口。

项目助手检查期间显示固定单行的最新推理摘要及经过秒数，长文本定位到最新末尾；尚未收到摘要时显示实际阶段。新摘要替换旧内容，收起态标题同步最新文字。结束或失败后停止更新并显示结果或错误。进度栏复用主题文字色和青色提示边，深浅主题及 390px 下保持一行，输入区位置保持稳定。

项目详情的成员、角色和权限列表填满各标签页剩余高度，列表内部滚动。顶部说明及操作区保持原位，角色状态和权限保存区位于列表下方。

项目详情各标签共用固定窗口高度 `min(740px, 100dvh - 100px)`。标题和标签栏固定，标签内容在内部滚动；切换基本信息、AGENTS.md、成员、角色、权限时窗口位置和尺寸保持一致。

项目详情与 HUD 可持续交互。点击 HUD 的展开、选项、输入、发送或设置，详情及当前标签保持打开，未保存字段保留。HUD 优先使用详情中正在查看的项目，详情关闭后回到顶栏当前项目。展开时保持详情的位置和尺寸，HUD 贴靠详情右侧，间距 8px，顶部对齐、高度相同；详情内容改变高度时 HUD 同步跟随，正文内部滚动。收起后 HUD 回到顶栏原位置。右侧剩余宽度不足 300px 时使用原有浮层布局，详情仍保持原位。Escape 在 HUD 内只收起 HUD。常规锚定及居中弹窗的外部点击关闭规则豁免 HUD 内部点击。

项目维护 HUD 固定在顶栏中间，紧凑态显示维护 AI 与状态。展开后以“对话消息”和“待办事项”分开展示本轮消息与当前项目卡片，问题原因默认折叠。每张问题卡包含选项与自由回答，选项点击时携带该卡片补充，失败保留输入；每张提案卡保留确认与暂不处理。输入与发送固定底部。更多入口仅包含项目备注和设置。阅读对话时新回复通过“查看最新回复”提示。HUD 外层使用半透明渐变玻璃、26px 背景模糊、细边高光和轻阴影，深浅主题保持正文清晰。Escape 收起并返回触发按钮；同一行动提醒手动收起后保持收起。390px 窄屏采用两侧 12px 留白。创建向导打开时 HUD 随向导进入同一弹窗层，关闭后恢复全局位置。详见 [项目维护 HUD](../engineering/PROJECT-HUD.md)。

设置菜单各项使用 16px 线条图标，与文字间距 10px，继承当前文字颜色及禁用反馈；装饰图标对辅助技术隐藏。主题切换同步切换太阳/月亮图标，重启状态更新保留图标及对齐。

右上角依次展示更新提示、用户称呼、设置菜单及连接状态。长称呼截断并提供完整 title；窄屏允许顶栏换行。设置菜单集中展示称呼、背景、主题、重启与关于，浮层保持在主内容之上，支持 Escape、焦点离开和点击外部关闭。重启进度持续显示在连接状态处。成员启停胶囊显示“启用 / 停用”，以文字、颜色和圆点表达状态，保留 switch 语义及请求中禁用反馈。

思考条以引擎 `/thinking` 的运行状态为权威，不按本地计时推断。执行状态无法确认（manual 或查询失败）时，思考条保持停住并显示事实状态：「停止请求已发送，结束状态确认超时」（本页发起过叫停）或「执行状态查询失败」；状态行与标题使用 `--danger`（浅色主题提高到 `#ff9fa9`），不再显示「思考中」。停止按钮保留，是否再次点击由用户决定；文案只报告操作失败或确认超时，不要求用户接手处理。叫停请求本身失败时提示「停止失败：原因」。取消请求已发出、服务尚未确认结束时显示「正在取消…」。停住状态只提示一次，展开仍可查看保留的过程内容。

对话框中有填写限制的字段，在输入、离焦或提交校验发现错误时使用 `--danger` 红色文字说明具体要求。错误靠近对应字段，设置 `aria-invalid` 和 `aria-describedby`，修正后清除；输入法组词期间保持输入稳定。必填、长度、格式、数字范围及整数约束复用 `dialogs.js` 的字段提示，业务校验和服务端失败通过显式错误状态显示。关闭重开清理过期字段错误。

## 验证与维护

角色新增授权直接更新选择。项目权限页仅在取消已保存的角色授权时提示影响，提示包含角色、权限名称及保存后生效的边界；取消尚未保存的新增授权保持安静。新建/导入向导仅在角色权限方案减少时提示核对职责，并注明最终提交后生效。

项目成员卡片保留启停、角色选择和工作区操作；更多菜单收纳编辑 profile、重置会话及危险色的移出项目。危险项使用分隔线，菜单支持方向键、Home/End、Escape、外部点击及视口边界避让。移出确认框初始聚焦取消，检查与提交期间禁用提交，阻塞事项提供具体处理入口；子确认框内点击保持项目详情打开。交互契约见 [项目成员移除](../engineering/PROJECT-MEMBER-REMOVAL.md)。

“换背景”弹窗以顶栏始终可见的“设置”按钮为定位参照；首次打开、背景加载及保存/恢复提示更新后保持右侧定位，并按视口边界避让。

“关于”显示当前运行代码身份：Release 安装显示版本号，Git 源码显示 tag/提交号并标注本地修改。缺少本地正式 tag 的源码显示开发版提交号，更新说明提示按提交记录核对差异。

“关于”提供“检查新版本”，点击后立即检查并显示等待、失败可重试或当前最新状态。有更新时显示目标版本及升级按钮；右上角新版本提示与该按钮使用同一个升级确认框，说明暂停服务、备份、自动启动、自动刷新与失败恢复。Git 工作区和缺发布清单的安装显示具体原因，升级按钮禁用。升级中禁止重复提交及同时重启；进度在关于窗口和连接状态显示，断线后持续核对回执，刷新页面可恢复监控。重启和升级完成新实例校验后清除监控记录，自动刷新当前整页加载资源；页面失败时保留错误提示。

“重启服务”确认框说明 Hermes 网关执行继续运行、服务启动后接回原执行；Codex 等本地执行最多等待 120 秒收尾，超时后停止。重启期间暂停新任务派发与工具写入，服务恢复后自动刷新界面。进度分别显示收尾本地执行、停止本地执行及等待服务启动。前端核对重启回执的上限为 5 分钟，超时保留回执；失败回执显示「重启失败：原因」及 logs/service-restart.log 路径。提交前释放页面事件连接并读取当前实例与回执。请求等待受理、等待服务恢复分别显示进度。支持按编号去重的引擎在请求丢失时允许一次同号补交。

项目向导第 5 步与详情“添加成员”复用勾选列表，顶部提供“创建 profile”和“刷新列表”，列表仅展示尚未加入当前项目的 Bot。刷新后和批量加入部分成功后，已入组成员从候选列表移除；列表为空时保留创建和刷新入口。创建独立窗口内选择宿主，提前说明取消选择后 profile 保留；创建成功返回列表、自动勾选并保留已有选择。详情“加入项目”和向导最终确认分别完成入组。创建窗口和列表底部动作保持滚动可达，窄屏至少验证 390px。

创建窗口的宿主入口固定显示 Hermes、Codex、DSH 三项，共用显示名称、Profile 标识、配置来源、模板引用和更多设置。Profile 标识初始为空、可编辑，扫描及切换来源/宿主保留用户输入。DSH 优先选择 desktop 来源，其余宿主优先 default，成功扫描保持状态区为空。Hermes/DSH 在默认收起的“更多设置”中同组展示可选模型与供应商，留空继承来源或默认主 profile，单项填写只覆盖对应项，窄屏同组纵向排列；两项初始为空，占位提示说明继承规则，切换来源保持输入原值，跨宿主分别保存手填草稿。Codex 在更多设置中显示可选模型，供应商输入隐藏。个人指令置于更多设置。DSH 创建独立命名 profile，同名冲突以红色提示并保留草稿；个人指令保存到新 profile 的人格配置。已有 DSH profile 通过成员候选列表选择，创建窗口省去数量、扫描目录和手动 HOME 接入区域。已创建 DSH 成员的 HOME 或 profile 失效时，成员卡片显示“宿主绑定失效”，保留成员与历史。详见 [DSH 独立创建](../design/2026-11-02-dsh-profile-create.md) 与 [模型供应商字段组](../design/2026-11-02-profile-provider-pair.md)。

DSH 成员编辑窗口提供“描述、人格、模型与供应商”三个页签。描述与人格保存位置保持原契约，模型、供应商与推理强度沿用项目覆盖和全局保存规则。保留部分保存回执、revision 冲突、插件依赖字段禁用和原因提示。移除指令、环境、Auto 的 DSH 控件及对应成员接口字段。Auto 在启动时检测插件并强制启用，设置菜单无开关。390px 窄屏完整显示三个页签。详见 [成员设置设计](../design/2026-11-02-dsh-member-settings.md)。

设置菜单的“远程节点”窗口并排提供“添加远程 Hermes”和“本机监听配置”。管理员可从空列表直接添加。Bot 身份只显示只读说明。刷新重新读取节点状态。每个节点独立展示已配对的远端成员、在线或吊销状态、连接方向、允许来源、实际连接 IP、连接代次、最近心跳、占用、MCP 指纹和可用版本。吊销需要单独确认。“云端连本机”的节点点击“重新签发”后复用配对弹窗，显示目标 profile、“复制命令”按钮、发给远程 Hermes 执行的指引与等待状态。引擎接受换发后显示结果，插件在远端报告保存结果。卡内按单个 IP 添加或移除来源，保留其他管理员并发所做的变更。

本地 profile 使用原显示名。远程节点名称、成员选择器和项目名册使用“profile（远程）”，多个同名远端通过括号内的序号区分。点名与入组使用各自的成员标识。

“添加远程 Hermes”先选连接方向。“本机连云端”由管理员粘贴远端插件的配对链接，页面展示引擎核验过的宿主成员、地址和短证书指纹，管理员确认后登记。“云端连本机”生成一次性邀请，页面提供可复制的云端连接命令。插件连接后展示已核验成员和实际来源，确认后登记并绑定该来源。页面读取本次服务端状态，区分等待、待确认、已登记、失败、取消和过期。失败指出设备、步骤和可执行的恢复动作。配对输入与邀请只保存在本次添加窗口，关闭时清除。

“本机监听配置”是引擎共用的次级弹窗，展示网卡、实际监听地址、来源、保存、停用和刷新操作。添加或切换到“云端连本机”且尚未开启监听时，直接打开同一弹窗。保存启用后续办原操作，取消返回原操作位置并保留原方向。零来源绑定可以启用监听。“本机连云端”独立于本机监听配置。

引擎拨号时，方向弹窗显示实际重试或已停止状态并给出最近原因，管理员可重开一轮。云端拨号且已断链时，页面显示离线，提示在云端 Hermes 私聊查询或重连。

节点卡的“切换方向”打开独立模态弹窗，沿用添加远程 Hermes 的两个方向选项。标题标明节点，选项标明当前方向。选择目标只更新表单，点击确认才执行切换；缺少端点时显示配对链接输入、预检和确认。两端地址、证书指纹、认证与成员名单读取状态收在“连接详情”。失败原因与重试操作直接可见。关闭或按 Escape 返回原节点按钮。桌面与 390px 深浅主题下均可使用。

前端变更按任务范围检查深浅主题、默认及自定义背景、长内容、关键组件状态、键盘焦点和窄屏。可访问性检查包括标签、对比度与操作可达性；本文记录源码基线，具体达标结论以实际验证证据为准。

Hermes 创建窗口自动继承模型凭证，配置来源下使用辅助文字说明默认来源及消息渠道隔离，省去认证勾选框。Bot 异常沿用系统通知样式，正文为名称与统一分类文案，刷新后保留。主动停止沿用已有弹窗提示。契约见 [执行异常反馈](../engineering/EXECUTION-ERRORS.md)。
