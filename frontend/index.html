项目详情

填写已存在的项目目录完成登记，项目文件会保留。

主目录始终保留。default 使用主目录，其他成员在“成员与目录”中创建或接管工作区。

任务自动重试耗尽后，向负责人发送阻塞汇总。未配置或负责人不可用时通知 user。

角色、权限、启停和工作目录属于当前项目。编辑宿主 profile 配置会影响该 profile 参与的其他项目。

角色是本项目的固定实体，改用稳定 ID 关联：改角色名不会断成员关联和授权。成员卡片选角色的候选来自这里定义的角色。

每项权限可选择当前项目已启用的成员。负责人同样需要授权；停用或移出会清除授权，再次加入后需重新授权。
